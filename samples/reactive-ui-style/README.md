# Reactive UI Style Sample

This sample keeps two things together:

- an Arcweft `.arcw` scene with interactive choices that can be hovered and pressed through the current shared renderer path;
- product UI sidecars that declare the intended retained UI style layers from both Arcweft-style authoring and CSS-style authoring.

Run the local sample fixture from the repository root:

```bash
just reactive-ui-style-sample
```

The command writes:

- `web/local/reactive-ui-style.awfb`
- `target/reactive-ui-style/interaction-states/neutral.svg`
- `target/reactive-ui-style/interaction-states/hovered.svg`
- `target/reactive-ui-style/interaction-states/focused.svg`
- `target/reactive-ui-style/interaction-states/pressed.svg`

The SVG state artifacts are generated by the retained UI renderer showcase. The
AWFB bundle carries `ui.program.json`, `ui.style.json`, and `ui.text.json`
sidecars so the sample is ready for the product UI style-resolution path once
that path is connected.

Current limitation: the player still renders this `.arcw` sample as dialogue and
choice UI. It does not yet instantiate the retained UI program from
`ViewProgramResource` or resolve the CSS/Arcweft style source layers into a
player-owned `UiLayerOutput`. See the seq06.11 request for that follow-up.
