# Reactive View Style Sample

This sample keeps two things together:

- an Arcweft `.arcw` scene with interactive choices that can be hovered and pressed through the current shared renderer path;
- product View sidecars that declare the intended retained View style layers from both Arcweft-style authoring and CSS-style authoring.

Run the local sample fixture from the repository root:

```bash
just reactive-view-style-sample
```

The command writes:

- `web/local/reactive-view-style.awfb`
- `target/reactive-view-style/interaction-states/neutral.svg`
- `target/reactive-view-style/interaction-states/hovered.svg`
- `target/reactive-view-style/interaction-states/focused.svg`
- `target/reactive-view-style/interaction-states/pressed.svg`

The SVG state artifacts are generated by the retained View renderer showcase. The
AWFB bundle carries `view.program.json`, `view.style.json`, and `view.text.json`
sidecars so the sample is ready for the product View style-resolution path once
that path is connected.

Current limitation: the player still renders this `.arcw` sample as dialogue and
choice View. It does not yet instantiate the retained View program from
`ViewProgramResource` or resolve the CSS/Arcweft style source layers into a
player-owned `ViewLayerOutput`. See the seq06.11 request for that follow-up.
