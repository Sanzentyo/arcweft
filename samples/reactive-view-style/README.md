# Reactive View Style Sample

This sample keeps two things together in the compiled `.arcw` source:

- an Arcweft `.arcw` scene with interactive choices that can be hovered and pressed through the current shared renderer path;
- compiler-owned native Style sheets with typed View application references.

Run the local sample fixture from the repository root:

```bash
just reactive-view-style-sample
```

The command writes:

- `web/local/reactive-view-style.awfb`
- `target/reactive-view-style/interaction-states/neutral.svg`
- `target/reactive-view-style/interaction-states/hovered.svg`
- `target/reactive-view-style/interaction-states/focused.svg`
- `target/reactive-view-style/interaction-states/pressed.svg`

The SVG state artifacts are generated by the retained View renderer showcase.
The AWFB bundle compiles its View program and Style resources from
`src/main.arcw`; only the authored text resource remains under `content/`.
This avoids merging a stale flat Style sidecar with the canonical sheet-owned
resource emitted by the compiler.

The View root carries ordered native sheet references. Rules select the root,
content, action, and interaction states through typed element and `.part(...)`
identities. Tokens and declarations stay owned by the sheet that is applied to
the View scope.
