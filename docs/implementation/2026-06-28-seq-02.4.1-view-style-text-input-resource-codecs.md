# seq-02.4.1 View, Style, Text, Theme, and Text-Input Resource Codecs

> Superseded naming note, 2026-07-08: the implemented product resource families
> are now `ViewProgramResource`, `ViewStyleResource`, `ViewTextResource`,
> `ViewInputResource`, and `ViewThemeResource` under
> `arcweft-bundle::resource_codec::view`. The current section magic values are
> recorded in `docs/implementation/view-resource-rename-2026-07-08.md`.

## Scope

This implementation adds compact product resource sections for the View families that were left future/dependent after the seq02.4 AudioGraph codec cut:

- `ViewProgramResource`
- `ViewStyleResource`
- `ViewTextResource`
- `ViewInputResource`
- `ViewThemeResource`

The implementation stays inside `arcweft-bundle`, reuses the existing seq02.1 `ProductResourceEnvelope`, and does not reopen the AudioGraph codec schema or seq02.5 patch v2.

## Design

### Container and codec families

Five new AWFB section kinds are added with stable container tags after the existing `PatchPlan` tag:

| Section kind | Container tag | Codec family | Codec tag | Magic |
| --- | ---: | --- | ---: | --- |
| `ViewProgram` | 16 | `ViewProgram` | 16 | `AWVP\r\n\x1a\n` |
| `ViewStyle` | 17 | `ViewStyle` | 17 | `AWVS\r\n\x1a\n` |
| `ViewText` | 18 | `ViewText` | 18 | `AWVT\r\n\x1a\n` |
| `ViewInput` | 19 | `ViewInput` | 19 | `AWVI\r\n\x1a\n` |
| `ViewTheme` | 20 | `ViewTheme` | 20 | `AWVH\r\n\x1a\n` |

The legacy umbrella `ProductSectionCodecKind::View` remains reserved and `Future`; the migrated product families are explicit and compact-first.

### Encoding shape

Each View family is encoded as a compact section envelope with:

- common header and magic from `ProductSectionCodecKind`;
- deterministic string table;
- deterministic public-id table;
- enum registry symbol naming the family;
- one required bytes field, `FIELD_VIEW_TRANSCRIPT = 1`, containing a deterministic typed transcript.

The transcript is intentionally not a product fallback format. It is an internal field under compact magic validation, mirroring the existing catalog migration approach. Product AWFB decode calls the family `decode_canonical_section` functions, so a raw JSON payload is rejected before the transcript is considered.

### `ViewProgramResource`

The schema covers:

- component view instructions;
- child spans;
- handler ids and AWBC function bindings;
- state schema digest/hash references;
- exported parts;
- semantic targets;
- cross-section adapter requirement references.

Patch compatibility is:

- `RestartRequired` when adapter requirements change;
- `CodeGenerational` when handler ABI, AWBC binding, or state schema hashes change;
- otherwise `ContentOnly` for layout/style-program-only changes.

### `ViewStyleResource`

The schema covers:

- Arcweft and CSS style source identity;
- source identities for inline, file, embedded file, and section-backed sources;
- token table;
- style rules and part rules;
- selector parts and selector depth;
- environment predicates;
- source-map references;
- external CSS descriptor references preserving file versus embedded-file identity;
- adapter requirement references.

`arcweft-bundle` does not parse CSS or open CSS files. It only serializes already lowered source identity and typed style declarations. Style changes are `ContentOnly` unless adapter requirements change.

### `ViewTextResource`

The schema covers:

- literal text;
- localized text keys;
- rich-text document references;
- display-frame references;
- source ranges;
- reveal policies;
- cursor policies;
- secure redaction metadata.

Agent observe/redaction changes are conservatively `RestartRequired`; normal text content/reveal/cursor updates are `ContentOnly`.

### `ViewInputResource`

The schema covers:

- `TextField`, `TextArea`, and `SecureField` metadata;
- input purpose;
- autocorrect;
- spellcheck;
- capitalization;
- enter key hint;
- multiline flag;
- secure policy;
- composition-on-blur policy;
- submit/change handler ids;
- adapter capability requirement references.

Until adapter requirement fingerprints are integrated, changes to input purpose, secure policy, multiline, field kind, or adapter requirements are `RestartRequired`.

### `ViewThemeResource`

The schema covers:

- `SystemColor` palette overrides;
- light/dark color values;
- color-scheme defaults;
- contrast defaults;
- reduce-motion default;
- text-scale default;
- dark-mode visual golden ids.

Palette and golden changes are `ContentOnly`.

## Decoder budgets

`ViewResourceBudget` extends the common section codec budget with family-specific limits:

- View program instructions;
- child spans;
- handlers;
- state schema hashes;
- exported parts;
- semantic targets;
- style rules;
- style tokens;
- selector depth;
- part count;
- environment predicates;
- source-map references;
- external CSS descriptors;
- text sources;
- input options;
- palette entries;
- transcript bytes.

The default values are intentionally high enough for product bundles but low enough to reject accidental or hostile unbounded sections.

## AWFB integration

`product.rs` gains optional compact sections for all five migrated View families. Decode uses the same source gate as the migrated catalog/audio families: a section must have compact family magic and must decode through `ProductResourceEnvelope`. There is no product JSON fallback for migrated View families.

`ArcweftBundle` gains optional fields and builder methods for the five resource families. These are `serde(default, skip_serializing_if = "Option::is_none")` so old JSON inspection fixtures remain readable without requiring a schema-version bump in this cut.

## Patch integration

`patch.rs` routes migrated UI section replacements through `migrated_ui_section_compatibility`, alongside the existing runtime and product catalog compatibility derivation paths. This keeps patch compatibility logic centralized in `arcweft-bundle` and avoids duplicating classification in runtime drivers or players.

## File layout

The production codec is split to stay below the AGENTS.md structural warning threshold:

- `crates/arcweft-bundle/src/resource_codec/view.rs` — facade and re-exports;
- `crates/arcweft-bundle/src/resource_codec/view/model.rs` — schema model;
- `crates/arcweft-bundle/src/resource_codec/view/codec.rs` — budgets, encode/decode, export view;
- `crates/arcweft-bundle/src/resource_codec/view/compat.rs` — patch compatibility routing.

## Tests added

`crates/arcweft-bundle/tests/view_resource_codecs.rs` specifies:

- deterministic bytes and decode equality for each UI family;
- unknown optional field skipping;
- unknown required field rejection;
- instruction-count, selector-depth, token-count, and text-source-count budget failures;
- CSS external descriptor file/embed preservation;
- palette fingerprint changes as `ContentOnly`;
- secure policy changes as `RestartRequired`;
- JSON fallback rejection/source gate behavior.
