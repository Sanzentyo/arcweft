# AW-AH-009.4.2 private Cut 2

## Scope

This cut implements only the independently mergeable private substrate from
`arcweft-aw-ah-009.4.2-dialogue-content-application-syntax-hir-ownership-production-reconciliation-final-contract.zip`.
It does not begin the public CST, AST, or HIR replacement series.

The syntax crate now privately owns:

- byte-exact LF/CRLF and ASCII space/tab indentation carriers;
- inline, indented, missing-content, dedent, and plan-boundary facts;
- checked bracket and colon application source surfaces;
- the bounded two-candidate recovery/failure vocabulary.

The HIR crate now privately owns:

- structured absolute, relative, and family-relative ID carriers;
- the existing 128-argument-bounded coordinate ordinal;
- coordinate and line-plan arena-ID carriers;
- postfix candidate failure facts;
- expression source roles and revision-bound insertion points;
- synthetic roles for index and dialogue candidate expressions.

All new fields are private. Construction that owns a source relation validates
the exact document limit and UTF-8 boundary. No syntax source string, fake zero
range, compatibility reader, or public legacy/final dual model was added.

## Deliberate non-goals

The final `HirDialogueContent` projection is not fixed in this cut. The design
package specifies that it must be a direct typed projection into the accepted
expression arena, but current `main` does not yet expose the required public
typed content/name/expression arena. Inventing a temporary projection would
create the compatibility residue prohibited by the package.

That payload is therefore owned by the Cut 5 public replacement series after
the accepted typed arena is available. The first public change to `SyntaxKind`,
`Expr`, or the final `HirExprKind` still begins one unmerged Cut 3–8 series.

This cut also does not:

- change parser classification or recovery;
- add public postfix/colon CST kinds;
- change `Expr::EntityRef` or any public expression variant;
- migrate sema, runtime-plan, verifier, compiler, LSP, CLI, or tooling;
- implement TTS or typed-resource behavior;
- touch `arcweft-resource-model`.
