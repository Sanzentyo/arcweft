# seq08.3.1 AWBC trait method call table and VM closure

This cut closes the AWBC side of the seq08.3 trait-method runtime dispatch work.

## Implemented

- Bumped the canonical AWBC codec version to `6`.
- Added `AwbcProgram.trait_methods`, indexed by `AwbcTraitMethodId`.
- Added `AwbcFunctionKind::TraitMethod`.
- Added `AwbcInstruction::AssignField` and `AwbcInstruction::CallTraitMethod`.
- Added canonical wire encoding/decoding, decode budget coverage, structural verification, dataflow verification, and compact VM execution for the new table and instructions.
- Extended AWBC v6 dynamic record and variant payloads to carry canonical field/case names. This is required for product VM execution of user-defined iterator state such as `self.current`, and avoids ordinal-only `field0` / `caseN` reconstruction.
- Extended variant patterns with canonical case names so pattern matching follows the same runtime naming contract as variant values.
- Added runtime-plan lowering for `RuntimePlan.trait_methods`.
- Lowered `RuntimeExpr::TraitCall` to direct trait-method calls instead of stringly intrinsics. Mutable local receivers now write their updated receiver state back to the local register.
- Lowered witness-backed `for` loops through executable `IntoIterator`/`Iterator::next` trait calls. Built-in iterator evidence stays on the existing intrinsic path.
- Added trait-method body control-flow lowering for returning `if` expressions, `let` bindings, and local field assignment chains. This keeps branch execution lazy instead of routing side-effectful method bodies through eager `select.bool`.
- Added executable AWBC tests for trait method table emission, witness call lowering, and identity `Iterator` witness execution through the product VM.

## Boundaries

- No compatibility layer or legacy fallback was added.
- The product step path uses the existing compact VM; it does not fall back to the structured runtime.
- Old ordinal-only dynamic record/variant reconstruction is not accepted in AWBC v6. Producers must emit field/case names through the canonical codec.
- The compiled-region eligibility pass still treats unsupported opcodes conservatively. This cut only makes the compact AWBC VM semantically complete for trait-method calls.
