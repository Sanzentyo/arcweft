## Adjudication

The repository rejects the archive's self-status. It is mechanically valid
but not implementation-ready:

1. It changes AW-AH-009.4.2's exact `HirIdSuffix`, `HirIdFamily`, and
   `parent_depth` types without later authority.
2. It does not preserve the exact Dialogue expression source roles,
   candidate-only synthetic roles, or ordinal contract.
3. Integer overflow is not representable by `magnitude: u128` plus an overflow
   flag, Duration has no exact direct payload/type projection, and decimal and
   compact-numeric invariants remain open.
4. It conflates named/elided type-region lifetimes with frame/line/etc.
   lifetime-registry scopes and omits the elided projection.
5. `HirPath { absolute: bool }` loses the current implicit/crate/self/super
   root distinction unless a missing module-context canonicalization contract
   is supplied.
6. `HirCallExpr { callee: ExprId }` cannot carry the accepted typed
   associated-capacity receiver from final HIR to the shared resolver.
7. It replaces the current Thread `Vec<FlowItem>` body with an unexplained
   `ExprId` and does not define the statement/block/runtime projection.
8. Dialogue/RichText leaves many referenced types, arena IDs, source roles,
   recovery records, constructors, and owner crates undefined.
9. It supplies an aggregate test table instead of the required
   variant-by-variant source/scope/recovery/limit lowering matrix.
10. Its `PRIMARY_REQUEST_COPY.md` is a short summary rather than the required
    verbatim request copy.

The manifest self row uses a zero hash/length sentinel while the manifest file
itself is nonempty. This does not invalidate the verified non-self rows, but a
corrected return must omit or explain that sentinel.

ordinary-call/shared-resolver authority, same-arena Dialogue/RichText children,
and deletion of ordinary `DialogueCall` and `MemoBlock` remain useful design
input. They are not sufficient public Rust schemas.

not be merged with the rejected return to invent a third model.
