# Seq05.4.1 follow-up: MCP/LSP REPL command-result adapters

Date: 2026-06-29
Depends on: seq05.4 CLI REPL host adapter integration

## Problem

Seq05.4 wires the concrete CLI Agent REPL bridge to `ReplCommandResult` and runtime-driver task ownership. Source inspection found MCP-backed Agent sessions used by the CLI remote path, but no stable MCP or LSP endpoint that accepts a REPL command string and returns a typed `ReplCommandResult` projection.

Adding transport-specific adapters before that surface exists would either duplicate CLI formatting or introduce protocol shims with no production caller.

## Request

Introduce narrow MCP and/or LSP REPL command-result surfaces only where a stable endpoint exists. The endpoint should accept typed REPL command input or raw input parsed by `parse_repl_input`, dispatch through the existing `ReplCommandContext` / `ReplCommandHandler` stack, and serialize structured typed evidence without reparsing human text.

## Required decisions

1. Which crate owns the MCP REPL command endpoint.
2. Which crate owns the LSP REPL command endpoint.
3. Whether JSON projection should move from `arcweft-cli` to a shared tooling crate or remain transport-specific.
4. How an MCP/LSP host obtains a runtime-driver `RuntimeTaskOwner` without introducing a scheduler registry.
5. How read-only trace mode is represented in protocol requests and diagnostics.

## Non-goals

- Do not redesign `ReplCommand`, `ReplCommandResult`, or `ReplCommandEvidence`.
- Do not move terminal human formatting into MCP/LSP crates.
- Do not add task state to MCP/LSP adapters.
- Do not add compatibility aliases or stringly command tables.

## Acceptance criteria

- MCP/LSP command execution uses `parse_repl_input` and typed `ReplCommandResult`.
- Protocol JSON is structured typed evidence, not formatted text.
- `:tasks` / `:cancel` use `RuntimeTaskReplCommandHost` over an existing runtime-driver owner.
- No product player crate depends on REPL, CLI, MCP, or LSP tooling crates.
- Tests cover host-unavailable, read-only rejection, task list, cancel all/task/scope, warm/codegen unsupported backend status.
