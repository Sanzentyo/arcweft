# Request: seq-06.13c vector clip and advanced mask render closure package

## Sequence position

Seq06.13c follows seq06.13 / seq06.13a. It must build on the retained
`ViewScene` / `ViewCompositor` path and the seq06.13a analytic clip and mask
sampling substrate already applied to production.

This request is independent of seq06.13b box-shadow work unless the designer
finds a concrete shared compositor contract that must be changed together.

## Problem

Seq06.13a intentionally implements only the first deterministic clip and mask
subset:

- inset / circle / ellipse / polygon analytic clip;
- external texture masks with auto / cover / contain / explicit size;
- repeat / no-repeat / repeat-x / repeat-y;
- alpha and luminance mask channels.

The remaining CSS features still produce structured diagnostics:

- `clip-path: path(...)`;
- `clip-path: url(...)`;
- gradient mask images;
- `mask: element(...)`;
- `mask-repeat: space` and `mask-repeat: round`.

These are too large for the 6.13a closure and need their own renderer contract,
fixture strategy, and production implementation plan.

## Goal

Design and implement the next production closure for vector clip paths and
advanced mask sources while keeping native and web on the same Arcweft-owned
wgpu route.

The result must not use browser DOM clipping, SVG filters, canvas fallback,
CSS-rendered hidden elements, screenshot-derived masks, or CPU-rasterized
Takumi output as the production path.

## Required decisions

- Choose the vector path substrate for `clip-path: path(...)`:
  - tessellated geometry;
  - analytic signed-distance coverage;
  - generated coverage texture;
  - or a clearly justified renderer-owned alternative.
- Define how fill rules, path winding, curves, close-path behavior, and
  degenerate segments are represented in typed Arcweft data.
- Decide whether `clip-path: url(...)` maps to reusable vector clip resources
  or remains an explicit unsupported diagnostic for this cut.
- Define the gradient mask contract:
  - linear / radial / conic support boundaries;
  - color stop interpolation;
  - alpha and luminance behavior;
  - repeat and sizing interaction.
- Define `mask: element(...)` requirements:
  - whether it depends on element capture resources from seq06.5/06.6;
  - how recursion and lifecycle are prevented;
  - how native/web evidence is captured.
- Specify `mask-repeat: space` and `round` exact distribution rules.
- Define error types and diagnostics for unsupported path commands, oversized
  geometry, unsupported gradient forms, cyclic element masks, and missing
  resources.

## Implementation requirements

- Produce a zip package with docs, overlay/patches, tests, and validation notes.
- Reuse existing `ViewClipGeometryPlan`, `ViewMaskPassPlan`, `ViewMaskTextureView`,
  and compositor shader boundaries where appropriate; redesign them only with a
  concrete reason.
- Keep resource acquisition in player/renderer adapters and keep planning data
  deterministic.
- Avoid compatibility shims and hidden fallback routes. Removed unsupported
  paths must fail through structured diagnostics until implemented.
- Update implementation notes and support matrices with exact supported /
  unsupported CSS features.

## Tests to specify and implement

- `path(...)` clips a fixture with lines and curves using both fill rules.
- Degenerate path commands produce typed diagnostics, not silent no-ops.
- Gradient mask alpha and luminance modes produce different deterministic
  coverage.
- `mask-repeat: space` and `round` resolve tile placement deterministically.
- Element mask either renders from a typed capture resource or emits the chosen
  structured diagnostic.
- Native/web visual smoke captures compare within documented drift thresholds.
- Existing seq06.13a clip/mask tests continue to pass.

## Expected output

Return a zip named like:

```text
arcweft-seq06.13c-vector-clip-advanced-mask-render-closure-YYYY-MM-DD.zip
```

The zip should contain:

- design markdown;
- implementation note;
- renderer/compositor overlay edits;
- CSS and retained-UI fixtures;
- focused Rust tests;
- optional ignored native/web visual smoke fixtures;
- validation instructions;
- updated support matrix.

## Non-goals

- Do not reimplement seq06.13 motion/keyframe behavior.
- Do not implement box-shadow here; seq06.13b owns that.
- Do not introduce DOM/canvas/browser fallback rendering.
- Do not redesign unrelated layout or cascade behavior from seq06.12.
