# Lang-01.5.1.1.2.1.1.1.1.1.1.1.2 — generic Match complete transcript and coverage closure correction

Status: `OPEN_DESIGN_REQUEST`

## Parent and split reason

This is a design-gated child of the accepted generic Match, runtime Need/View
admission, and runtime task persistence corrections. Those packages correctly
require an exhaustive stable Match transcript and bounded typed usefulness,
but their sketches do not identify constructible current owners for every
checked resolution, accepted field/case identity, and product/sequence coverage
row in the repository.

Cut 1b therefore implements the exact current subset and rejects every missing
family before publication. Do not replace those rejections with source spelling,
raw HIR IDs, display/debug text, copied nominal layouts, or a conservative
`nonexhaustive` success value.

## Decisions required

Return one coherent design that closes all of the following.

1. The stable payload transcript for every current
   `CheckedExpressionResolution` family, including ProjectItem/Entry,
   Method/DialogueView/AgentField, StageLook, Await, Choice, Try, implicit
   callable/parameter, Pipe, View, Style, dialogue, and postfix-bracket facts.
   Each row must name its existing accepted owner or define the same-cut final
   owner and deletion of the superseded lookup-only evidence.
2. The exact accepted semantic identity for Entity patterns and
   Character/Builtin closed variant owners, including source-order case identity
   and payload type without raw item IDs or source names.
3. A checked record-pattern field row owned by sema, mapping each authored
   source child to its accepted `RuntimeRecordFieldId`, field semantic identity,
   field type, nominal semantic identity, and canonical `TypeLayoutHash`.
   Transcript construction must consume this row rather than resolving names.
4. The private bounded Maranget matrix types and specialization algorithm for
   tuple and record products, constant arrays, symbolic Vec/Slice/Seq exact and
   rest length partitions, Or alternatives, literals plus Other, entity/open
   residuals, Never, Choice, and every accepted closed variant family.
5. Exact constructor-domain and witness transcripts for nested products and
   sequences. Work counters remain diagnostic-only and all limits use checked
   `u64` accounting before allocation/descent.
6. The stable declaration/body path bridge for every executable current body
   family still absent from HIR authority, including any line-plan/Choice/View
   declaration rows that can contain Match.
7. The compile-clean/deletion order that replaces Cut 1b's typed unsupported
   branches only when each final authority is constructible. No temporary
   source resolver, parallel coverage algebra, or whole-catalog digest is
   permitted.

Every Arcweft-owned version marker remains exactly `1`.

## Current safe substrate to preserve

- exhaustive expression/statement/pattern/body typed edges;
- declaration-rooted stable paths and checked callable joins;
- stable literal, binding, guard, arm, and Match digest grammar;
- canonical sema runtime nominal schema/layout projection;
- Bool/Unit/Option/Result/project-enum total-payload coverage;
- false-guard precedence, dynamic-guard usefulness, hard non-exhaustiveness,
  and complete rollback on limits; and
- typed `UnsupportedIdentity`/`UnsupportedCoverage` failure before publication.

## Required tests

- exhaustive current expression/pattern enum-variant transcript coverage;
- HIR arena/ID/span/source-format perturbation with equal semantic digests;
- callable contract, nominal layout, accepted field/case, and arm/child order
  sensitivity;
- canonical integer radix, duration-unit, float-bit, text, entity, and accepted
  identity differentials;
- generated finite-domain differential checks against the matrix algorithm;
- tuple/record/array products, Option/Result/Choice/project/Character/Builtin
  variants, symbolic sequence partitions, Or overlap/redundancy, Never, and
  open residuals;
- exact-limit/one-over checks for arms, rows, alternatives, nodes, depth,
  partitions, specializations, unreachable rows, witnesses, and transcript
  bytes, with no partial publication; and
- compile/structure negatives for source spelling, raw HIR IDs, copied layout,
  wildcard success, parallel models, and version bumps.
