Current production has one closed project callable identity:

```rust
pub enum CallableDeclarationKey {
    Existing(CallableDeclarationId),
    TraitRequirement(TraitMethodRequirementId),
    ImplMethod(ImplMethodDeclarationId),
    Flow(FlowDeclarationId),
}
```

`TraitMethodRequirementId` retains the structural Trait declaration and method.
`ImplMethodDeclarationId` retains an `ImplDeclarationId`, method kind, and
method, where the Impl owner is structurally distinguished by source ordinal.
These variants are used by HIR symbol publication and sema. They cannot be
losslessly represented by AW-AH-009.4.3's frozen source-owner variant:

```rust
HirDialogueLineSourceOwner::Callable(CallableDeclarationId)
```

The active implementation can therefore derive final generated IDs for
Functions, extern capability Functions, Views, Predicates, Proofs, and Flows,
but must not invent method-owner segments for Trait requirements, trait Impl
methods, or inherent methods.
