# Request: seq-06.13e CSS inset box-shadow rendering package

## Sequence Position

Seq06.13e follows:

- seq06.13b box-shadow renderer/compositor substrate;
- seq06.13c vector clip and advanced mask render closure;
- seq06.13d typed CSS `box-shadow` lowering from Takumi into
  `ViewBoxShadowList`.

Seq06.13d deliberately lowers `inset` shadows into typed
`ViewBoxShadowKind::Inset` but leaves rendering as
`ViewBoxShadowPlanError::InsetUnsupported`. This request closes that renderer gap.

## Goal

Design and implement Arcweft-owned inset `box-shadow` rendering for the direct
wgpu UI compositor path.

The result must render CSS/Takumi `box-shadow: inset ...` values that already
arrive as typed `ViewBoxShadowKind::Inset`, without using DOM, browser CSS,
canvas, SVG filters, bitmap snapshots, CPU raster, or source-string fallback
paths.

## Required Decisions

- Define the inset pass model in `arcweft-render-wgpu`:
  - pass ordering relative to background, children, clip, mask, filters, and
    blend;
  - whether inset shadows draw before or after child paint nodes;
  - how inset interacts with `clip-path`, rounded clips, masks, opacity, and
    isolation.
- Decide whether `ViewBoxShadowPassPlan` grows a unified outer/inset pass list or
  a separate `UiInsetBoxShadowPassPlan`.
- Define geometry for inset shadows:
  - inner shadow body rect;
  - spread handling, including negative spread;
  - blur radius;
  - rounded border radius;
  - degenerate or zero-area boxes.
- Define the shader contract:
  - whether existing `PASS_BOX_SHADOW` is extended with a kind flag;
  - whether a new `PASS_INSET_BOX_SHADOW` is cleaner;
  - uniform layout, pipeline key, and bind group impact.
- Define exact diagnostic behavior:
  - replace `InsetUnsupported` only when inset rendering is actually
    implemented;
  - keep `NonFinite` and degenerate geometry diagnostics typed;
  - do not silently drop non-empty inset shadows unless they are canonical
    identity paint.
- Decide visual evidence policy:
  - focused analytic plan tests are required;
  - GPU smoke tests are required;
  - pinned native/web exact PNG promotion remains manual unless this package
    explicitly performs it on a pinned environment.

## Implementation Requirements

- Keep CSS parsing/cascade/lowering in Takumi/Takumi-adapter; this package
  should consume existing typed `ViewBoxShadowKind::Inset`.
- Keep renderer code in `arcweft-render-wgpu`; do not add platform, DOM, web,
  browser CSS, canvas, SVG, or CPU raster rendering routes.
- Preserve outer shadow behavior and pass order from seq06.13b.
- Preserve `filter: drop-shadow(...)` as `ViewFilter::DropShadow`.
- Update `ViewBoxShadowPassPlan` or introduce a named inset plan with clear
  ownership and tests.
- Update compositor pass planning and WGSL/uniforms if needed.
- Update docs/implementation coverage matrix to mark inset visual rendering
  supported only after tests pass.
- Keep implementation notes separate from stable design docs.

## Tests To Specify And Implement

- Inset shadow no longer returns `ViewBoxShadowPlanError::InsetUnsupported`.
- One inset shadow produces deterministic geometry and visual outset/inset
  metadata.
- Multiple inset shadows preserve CSS list order and deterministic paint order.
- Negative spread is deterministic.
- Transparent and zero inset shadows canonicalize to no pass.
- Non-finite fields still emit typed diagnostics.
- Outer and inset shadows in the same list preserve the intended compositor
  ordering.
- Existing outer box-shadow tests remain unchanged.
- GPU smoke test covers at least one rounded inset shadow and one mixed
  outer+inset card.
- Takumi adapter test confirms CSS `box-shadow: inset ...` reaches the renderer
  plan as an inset pass through typed data.

## Constraints

- Do not redesign seq06.13d typed CSS lowering unless a concrete flaw is found.
- Do not introduce compatibility shims, fallback renderer paths, source-string
  CSS scanning, or hidden browser/DOM behavior.
- Do not claim direct visual support in coverage until typed renderer tests and
  GPU smoke tests pass.
- Keep exact PNG promotion separate from implementation unless the package runs
  in the pinned native/web visual-golden environment.
