# Seq-04.4 Request: Cache Explain Query Evidence Package

## Sequence Position

This follows seq04.2 and preferably seq04.3. It exposes persistent compiler
query evidence through `arcw cache explain`.

## Request

Design and implement query-level `arcw cache explain` output for persistent
compiler query records and soft-miss evidence.

Return the final work as a zip package with implementation, tests, docs, and
validation.

## Required Scope

- Extend `arcw cache explain` so a user can inspect a persistent compiler query
  logical item or query key.
- Show key inputs, compiler identity, source digest, payload kind, schema,
  object digest/length, hit/miss status, soft-miss reason, and recovery action.
- Keep output deterministic and machine-readable where existing CLI conventions
  do so.
- Avoid duplicating validation logic in CLI; reuse typed adapter/project-loader
  evidence from seq04.2/04.3.

## Non-Goals

- No new cache write policy.
- No runtime-plan/bytecode/link-plan reuse.
- No interactive TUI or non-deterministic pretty reporting.

## Expected Zip Contents

- `overlay/` implementation.
- CLI tests and focused adapter tests.
- `docs/implementation/seq-04-4-cache-explain-query-evidence-2026-06-28.md`
- `VALIDATION.md`.
- `README.md`.
