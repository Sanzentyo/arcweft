## Why this correction is required

The accepted synthetic-role correction requires this exact structural row:

```text
role:             ClosureEnvironment
owner:            SyntheticOwner::Expr
child kind:       HirIdKind::Expr
ordinal:          exactly 0
source anchor:    closure introducer end
generator:        one environment child per source-backed closure ExprId
tag:              0x0a
```

The accepted final leaf-expression schema simultaneously retains:

```rust
pub struct HirClosureExpr {
    scope: ScopeId,
    parameters: Box<[HirClosureParameter]>,
    result_type: Option<TypeId>,
    body: ExprId,
    captures: Box<[CaptureId]>,
}
```

It defines no environment field, environment payload variant, typed reference,
or consumer. The later generator correction requires 1,024/1,025 capture
rollback to include "the closure environment", but still does not define what
the environment Expr contains, how `HirClosureExpr` refers to it, or who reads
it.

Repository evidence at committed `main`
`f587e75750d9c5d9b6d8c84e0f098a4cfa80f68b` does not close that gap. The active
Proof integration observed during audit was dirty and unaccepted; it therefore
counts only as diagnostic evidence. In that integration:

- `HirClosureExpr` still owns `scope`, parameters, result type, body, and
  ordered `CaptureId`s only;
- capture lowering allocates `HirCapture` records directly under
  `SyntheticRole::ClosureCapture` in first-use order;
- source, sema, and compiler consumers read the typed capture arena and closure
  capture list, not an environment Expr;
- no production final-HIR lowerer allocates `ClosureEnvironment`; and
- the role is absent while later fingerprint tags retain an unexplained
  `0x0a` gap, which is not an accepted direct-deletion result.

Adding a synthetic Error/Unit/Tuple/Record expression merely to satisfy the
role table would invent payload and runtime meaning. Leaving a tag gap and
test-only key would preserve dead schema. The final authority must therefore
select and completely specify exactly one outcome:

1. `RETAIN`: define the real environment Expr payload/reference/source/lifetime
   and every production consumer; or
2. `DELETE`: remove the role and every associated tag, matrix, generator,
   rollback, and reserved-gap claim because captures are the sole final owner.

`Reserved for future use`, an unreferenced synthetic child, and a test-only
allocation are not implementation-ready outcomes.

### 2. Complete retained authority, if `RETAIN`

If a distinct environment Expr is required, define without invention:

- its exact final `HirExprKind` and complete payload fields;
- the `environment: ExprId` (or other accepted typed reference) added to the
  sole closure owner, with constructor and module validation;
- allocation order relative to closure root, scope, parameters, body, and
  captures;
- the exact source insertion and source-query role;
- whether the payload stores capture IDs, locals, values, access modes, or
  another typed record, including ordering and duplicate behavior;
- scope, poison, visibility, liveness, retry/reuse, and retirement rules;
- the sema/runtime/compiler consumer and the deletion of any previous parallel
  capture reader in the same authority switch;
- exact descendant, expression, capture, source-component, diagnostic, and
  total-slot accounting; and
- direct exact/one-over and perturbation tests, including 1,024 distinct
  captures followed by one-over rollback of closure, environment, captures,
  source rows, facts, caches, and counters.

An Error, Unit, tuple, record, source string, raw ID, sentinel, or opaque
side-table payload is not an acceptable unspecified environment.

### 3. Complete direct deletion, if `DELETE`

- every reserved compatibility hole or fixture-only allocation; and
- every consumer branch that assumes a separate environment Expr.

Give the complete resulting contiguous role/tag table and fixed fingerprint
vectors. Decide the transcript version/domain and renumbering based on actual

not preserve an unreleased gap through an alias, deprecated variant, reserved

Prove that `HirClosureExpr::captures()` plus the typed capture arena owns all

### 4. Lifetime and persistence boundary
