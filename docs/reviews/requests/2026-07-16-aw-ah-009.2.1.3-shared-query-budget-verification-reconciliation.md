# Design request: AW-AH-009.2.1.3 shared query budget and verification reconciliation

- Date: 2026-07-16
- Kind: independently throwable final-design correction
- Output language: English
- Production changes: prohibited

## Sequence and objective

This request follows the implemented AW-AH-009.2.1 semantic query and LSP
adapter. It may be designed independently of AW-AH-009.2.1.1 and .2, but its
implementation follows any source-adapter API selected by .2. It precedes
AW-AH-009.2.2 rename.

The final AW-AH-009.2.1 package requires one request budget shared by reference
collection, symbol/member candidate resolution, core cursor query, declaration
copying, target adaptation, exact identity checks, and admitted query errors.
The current implementation bounds these collections but does not expose a
single ownership-safe budget across sema and LSP. Freeze that missing boundary
and the direct verification cut. Do not redesign nominal identity, source index
contents, query result categories, or `LocationLink` composition.

## Required decisions

1. One exact request-budget type, owner, constructor visibility, and borrowing
   model that allows sema and the LSP adapter to charge the same counter without
   putting protocol or I/O types into sema.
2. Exact charge points and order for parser facts, project-symbol candidates,
   typed member candidates, declaration copies, target adaptations/identity
   checks, and admitted error candidates. A failing operation consumes the unit
   that discovers failure.
3. Inclusive production maximum `4_096`, same-crate reduced-limit test hooks,
   checked addition/conversion, overflow behavior, and prohibition on
   client/profile/environment overrides.
4. Cache behavior: cached Sans-I/O inventories/results must still charge or
   otherwise account for uncached adapter work without letting a cache hit
   bypass the request maximum. Protocol links remain uncached.
5. The final direct-test organization for the package's O/M/C/A/S/K/L/N matrix,
   including `arcweft-lang-sema` real parser → source → HIR → checker →
   reference-inventory → query tests and LSP accepted-generation integration
   tests. Define reusable typed fixture ownership without copying a second
   registrar or using source gates.
6. Completion accounting for every test-matrix row, exact/one-over each selected
   limit, deterministic permutations, arithmetic overflow, and workspace
   validation. Missing rows must remain explicit rather than being inferred
   from nearby tests.

## Required tests and validation

The returned design must prescribe focused character/sema/project-loader/LSP
tests, stable workspace check, workspace Clippy with warnings denied, format,
the applicable `just` cut-point, and the canonical structural audit. It must
separate repository-external blockers from implementation failures and must not

evidence.

## Constraints

No compatibility budget, global mutable counter, hidden saturating arithmetic,
partial successful result, source gate, unbounded candidate vector, CSS/Takumi,
rename, signature help, or redesign of Style/View/proof and already verified
AW-AH-009.2.1 substrate.
