# Design request: seq-06.11d.2.1.1.4 View-part contextual tooling contract

- Date: 2026-07-15
- Kind: independently throwable final-design correction
- Production changes: prohibited
- Prerequisite: final d.2.1.1.2 source/link contract
- Parallelism: may be designed in parallel with d.2.1.1.3

## Goal

Close application-edge-backed Style-part symbol binding and the complete
formatter/LSP metadata lifecycle. The current partial implementation provides
typed owner-local/public declaration metadata, hover, definition, references,
and export-local completion. It intentionally does not bind reusable selector
tokens by text, and therefore does not implement selector references, rename,
symbols, semantic tokens, or cross-document atomicity.

## Required decisions

1. Define the checked Style application/call-edge graph that maps each selector
   part token to zero, one, or many typed local/public symbols.
2. Define binding ownership between sema, compiler/tooling, and LSP without a
   sema-to-LSP dependency or copied registry.
3. Define completion for export operands, owner-local selectors, direct callee
   exports, and reusable-sheet unions with owner detail.
4. Define hover, definition, and references for all local/public operands and
   contextual selector bindings. External public definition must stop at the
   export declaration, not the private target.
5. Define two atomic rename operations, collision checks, ambiguous reusable
   binding failures, and exact no-edit behavior for stale versions.
6. Define document/workspace symbols and semantic-token types/modifiers,
   including tokens with mixed local/public contextual bindings.
7. Define exact source identity/version inputs, cache keys, linked/open document
   locations, invalidation, and atomic failure when any document is stale.
8. Preserve formatter valid-only canonicalization and malformed-byte
   preservation; do not turn formatting into semantic export creation.

## Required tests to specify

- completion never exposes a private cross-boundary name or `CallView` export;
- equal local/public text remains two symbols and two rename operations;
- reusable selector one/many/mixed bindings have canonical results;
- ambiguous local/public rename returns its typed error and no partial edits;
- definition, references, hover, symbols, and tokens work across modules;
- stale source identity/version cancels a multi-document edit atomically; and
- malformed formatting is byte-preserving and idempotent around valid nodes.

## Constraints and expected output

No text/suffix heuristic, source gate, CSS spelling, global public-part
namespace, or transport-specific semantic owner is permitted. Generic LSP
session transport remains outside the semantic index. Return a self-contained
decision-complete design package with exact Sans-I/O input/result types,
protocol projection, application-graph ownership, failure states, tests,
caller migration, and `OPEN_QUESTIONS` equal to `none`.
