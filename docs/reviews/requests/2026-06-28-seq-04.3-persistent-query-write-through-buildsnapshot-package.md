# Seq-04.3 Request: Persistent Query Write-Through and BuildSnapshot Evidence Package

## Sequence Position

This follows seq04.2. It adds write-through for safe parse/HIR objects and
records cache reuse evidence in build snapshots.

## Request

Design and implement persistent compiler query write-through for safe parse/HIR
objects, plus `BuildSnapshot` evidence for hits, misses, stale records, corrupt
objects, conservative invalidations, and rebuild reasons.

Return the final work as a zip package with implementation, tests, docs, and
validation.

## Required Scope

- Persist seq04.1 `.awbo` parse/HIR objects through the existing filesystem
  object/record store after successful rebuild.
- Keep cache writes adapter-owned and deterministic.
- Record query-level reuse evidence in `BuildSnapshot` or the existing snapshot
  evidence model without mixing transient progress notes into stable design
  docs.
- Ensure `arcw build --watch` prefers valid in-memory cache entries over disk
  records and falls back to disk only when appropriate.
- Preserve deterministic AWFB content roots across repeated clean and cached
  builds.

## Non-Goals

- No interface summary reuse unless seq04.5 has provided the schema.
- No semantic/typecheck/runtime-plan/bytecode/link-plan reuse.
- No public compatibility guarantee for compiler-private `.awbo` payloads
  across compiler identities.

## Expected Zip Contents

- `overlay/` implementation.
- Tests for write-through, snapshot evidence, watch in-memory precedence, and
  repeated build output determinism.
- `docs/implementation/seq-04-3-persistent-query-write-through-buildsnapshot-2026-06-28.md`
- `VALIDATION.md`.
- `README.md`.
