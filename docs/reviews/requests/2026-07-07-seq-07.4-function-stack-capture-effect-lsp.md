# Request: Function Stack Capture, Effect, Lifetime, and LSP Evidence

## Context

Runtime functions currently capture deterministic local bindings at evaluation
time. The remaining language contract needs explicit capture inventory,
effect-row composition, suspension-boundary diagnostics, and tooling evidence.

## Required Decisions

- Define capture inventory format for closures and function values.
- Specify diagnostics for captures crossing `await`, `yield`, thread,
  line-task, defer, save/load, and resource lifetime boundaries.
- Define how closure effects compose into existing effect rows.
- Define LSP inlays for inferred closure/function types.
- Define lints for numeric fallback inside inferred closure bodies.

## Implementation Order

1. Add capture inventory collection in sema. Implemented: `TypeCheckReport`
   now carries per-closure capture inventory keyed by stable expression IDs,
   with tests for immutable local capture and nested closure parameter capture.
2. Add lifetime/effect diagnostics for suspension boundaries. Implemented
   for borrowed closure captures crossing `await`, `yield`, `thread`, and
   `defer` boundaries: sema now emits
   `sema.typecheck.borrowed_closure_capture_crosses_boundary` with structured
   capture name, borrowed type, lifetime labels, and owning boundary fields.
   The checker uses typed suspension-boundary variants internally and converts
   them to stable labels only when constructing diagnostics.
   Closure body effect collection now registers each closure literal as a
   synthetic private callable, so creating a function value does not perform or
   leak the closure body effects into the enclosing callable. Direct calls
   through a local closure binding, such as `let f = || ...; f()`, add a local
   effect edge from the caller to that synthetic closure callable. Partial
   application of a local closure binding now carries the same closure effect
   callable to the partial alias without performing the body effects until the
   alias is called. Immediate closure calls such as `(|| -> String { ... })()`
   now compose the body effects into the caller, and partial immediate closure
   applications carry the same closure callable to their aliases without
   composing until the alias is called. Built-in collection higher-order
   methods `map` and `filter` now compose closure argument body effects into
   the caller for direct closure arguments, local closure aliases, and partial
   closure aliases. User-defined top-level higher-order calls, including
   data-last method fallback calls, now compose closure argument body effects
   when the callee directly invokes the matching function-typed parameter.
   Curried later call groups, destructured callback parameters, callback
   invocation hidden inside returned/stored closures, and LSP-facing effect
   evidence remain part of this request.
3. Add runtime-plan metadata only where it is needed by runtime diagnostics or
   save/load policy.
4. Add LSP inlays and lints from the same sema evidence. Numeric fallback
   lint is implemented for unsuffixed integer/float literals and numeric
   sequence summaries that fall back inside inferred closure bodies:
   `sema.numeric.fallback_in_inferred_closure` carries the literal family and
   fallback type. LSP inlays are implemented for inferred function-valued
   `let` bindings without explicit type ascriptions, including inferred
   closures and inferred partial-placeholder functions. Arbitrary expression
   inlays remain open until sema expression evidence carries source spans
   rather than traversal-only expression IDs.

## Tests To Specify

- Capture of immutable local in pure closure succeeds.
- Capture crossing `await` is rejected when lifetime policy forbids it.
  Implemented for borrowed local captures.
- Capture crossing yield/thread/defer boundaries reports the owning boundary.
  Implemented for borrowed local captures.
- Function type inlay appears for inferred closures. Implemented for inferred
  function-valued `let` bindings and covered by LSP request tests.
- Numeric fallback lint appears inside inferred closure body. Implemented for
  scalar unsuffixed integer/float fallback and numeric sequence fallback.
- Closure creation does not infer body effects on the enclosing callable.
  Implemented for closure literals bound to locals, with direct local calls
  composing the body effects back into the caller.
- Partial application of a local closure binding does not infer body effects
  while the partial function value is created, and a later call through that
  alias composes the body effects into the caller.
- Immediate closure calls compose body effects into the caller, while partial
  immediate closure application remains effect-free until the partial alias is
  called. Implemented for parenthesized closure callees.
- Built-in `map` and `filter` compose closure argument body effects into the
  caller. Implemented for direct closure arguments, local closure aliases, and
  partial closure aliases.
- User-defined higher-order functions compose closure argument body effects
  into the caller when the callee directly invokes the matching function-typed
  parameter. Implemented for direct top-level function calls with named
  first-call-group parameters and data-last method fallback calls, covered by
  positive/negative sema tests.

## Constraints

- Do not make `arcweft-core` depend on sema, LSP, CLI, or OS adapters.
- Keep diagnostics structured with stable codes.
- Do not redesign existing effect capability policy unless evidence shows a
  concrete flaw.

## Expected Output

- Sema capture/effect data model.
- Structured diagnostic tests.
- LSP/tooling tests and docs updates.
