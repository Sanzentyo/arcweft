# Request: seq-06.11b View scene compositor player path integration package

## Sequence position

Seq06.11b follows seq06.11/06.11a. It is the normal-player-path connection for
the View scene and compositor substrate from seq06.9.

This request can be designed in parallel with seq06.11a, but implementation
should consume the final direct paint/extractor contract rather than inventing a
second paint path.

## Problem

`arcweft-render-wgpu` has `ViewScene`, `ViewPaintNode`, `ViewCompositor`, and
`ViewDirectPrimitiveRenderer` contracts, but the ordinary prepared-frame player
path still primarily renders rectangles, images, and glyphon text directly.

The result is a split surface:

- compositor/effect substrate exists;
- direct primitive lowering exists;
- normal native/web player frames do not yet consume the full `ViewScene` /
  `ViewPaintNode` graph as the shared path.

Without this connection, CSS/Takumi compositing work remains test substrate
rather than usable player View.

## Goal

Design and implement the shared native/web player connection that renders
Arcweft View through `ViewScene` / `ViewPaintNode` / `ViewCompositor` in the normal
frame path.

The same frame data must work for native and web. Web must not use DOM/CSS/HTML
UI as the visual output.

## Required decisions

- Define where `ViewScene` is attached to `PreparedFrame` or equivalent frame
  data.
- Define a concrete `ViewDirectPrimitiveRenderer` implementation for the existing
  wgpu renderer:
  - solid rect;
  - rounded rect;
  - border;
  - linear gradient;
  - image;
  - glyph run or explicit text handoff;
  - selection/caret/composition primitives where applicable.
- Decide how existing rectangle/image/text paths migrate:
  - keep them as non-View frame primitives;
  - or lower View-owned pieces into `ViewScene` while leaving dialogue legacy
    primitives until a later cut;
  - document the migration boundary.
- Define compositor usage:
  - when to use direct primitive rendering only;
  - when to allocate offscreen group targets;
  - how backdrop filters copy from the parent target;
  - how diagnostics are surfaced when a compositor requirement is unsupported.
- Define native/web resource providers for masks/images without moving I/O into
  data-format crates.
- Define visual evidence:
  - direct-only scene;
  - filter/drop-shadow scene;
  - backdrop scene;
  - high-DPI scale fixture.

## Implementation requirements

- Produce a zip package with docs, overlay/patches, tests, and validation notes.
- Preserve the existing shared renderer surface for non-UI dialogue/text until
  an explicit migration request replaces it.
- Do not route UI through browser DOM/CSS, hidden HTML elements, canvas 2D, or
  CPU-rasterized Takumi output.
- Keep platform surface acquisition and event loops in native/web player
  adapters.
- Keep renderer and adapter crate boundaries aligned with AGENTS.md.

## Tests to specify and implement

- A direct-only `ViewScene` renders through the normal native/web frame path.
- A compositing group with blur/drop-shadow produces deterministic pass plans
  and a smoke-rendered frame.
- A backdrop-filter group copies from parent target exactly once in the expected
  plan.
- Unsupported compositor requirements produce typed diagnostics.
- Web sample output contains no DOM View overlay for Arcweft View content.
- Native and web visual smoke captures compare at default and high-DPI scale.
- Existing `css-style-parity` and `reactive-view-style` sample bundle generation
  still works.

## Expected output

Return a zip named like:

```text
arcweft-seq06.11b-view-scene-compositor-player-path-integration-YYYY-MM-DD.zip
```

The zip should contain:

- design markdown;
- implementation note;
- renderer/player overlay edits;
- native/web sample or fixture updates;
- focused renderer and player tests;
- validation instructions;
- explicit deferred migration items.

## Non-goals

- Do not implement full CSS layout/cascade coverage; seq06.12 owns that.
- Do not implement advanced clip/mask/path closures unless required by the
  minimal compositor fixture; seq06.13a owns that.
- Do not remove existing dialogue/text primitive paths unless this package
  provides complete replacement evidence.
