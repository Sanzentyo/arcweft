# Request 06.1: UI Style, Text Input, and Direct wgpu Rendering Substrate

## Sequence Position

This is a seq06-adjacent presentation request. It can proceed after seq02.4
AudioGraph is closed and in parallel with seq02.5 through seq05. Product View
resource codec work belongs in the separate post-seq02.4 request
`2026-06-27-seq-02.4.1-view-style-text-input-resource-codec.md`.

This request is the umbrella for the conversation's UI/style/TextField substrate.
It delegates renderer-specific Takumi lowering to seq06.2 and platform IME
adapters to seq06.3, but must define the shared data contracts those requests
consume.

## Request

Design and implement the Sans I/O UI/style/text-input substrate and renderer
contract for direct wgpu UI rendering without CPU-raster fallback surfaces.

## Required Decisions

1. Public display text is one `Text` view; rich/localized/display-frame text are
   retained `ViewTextSource` variants.
2. `pub style name` is the default Arcweft style syntax, with `pub style name:
   .Css` for CSS.
3. External CSS uses `from file(...)`; embedded CSS uses `from embed(...)`.
4. Component overrides use `.style {}` and `.style(.Css) {}` as ordered layers.
5. Component internals are targetable only through exported typed parts.
6. Dark mode and accessibility preferences are `PresentationEnvironment` fields.
7. Japanese/IME input uses session-scoped atomic text-input batches and a
   composition visual overlay.
8. Focus routing uses `FocusTree` and `TextInputSessionId`; pointer routing uses
   `HitTree`.
9. View DSL lowering produces `ViewProgram`/`ViewInstruction` data before retained
   fragments, not stringly runtime parsing.
10. Renderer-facing UI data lowers to `ViewScene` primitives for wgpu rendering.
11. Takumi CSS/layout/stacking integration is implemented in seq06.2, not as a
    CPU-raster surface path.
12. Platform IME adapters are implemented in seq06.3 and may not leak OS APIs
    into presentation/View/renderer crates.

## Required Implementation Order

1. Add `arcweft-presentation` appearance/focus/text-input data modules.
2. Add `arcweft-view` style/text-source/TextField/ViewProgram data modules.
3. Add `arcweft-lang-syntax` style and view AST surfaces.
4. Add `arcweft-render-wgpu::view_scene` renderer-facing primitive data.
5. Wire module facades and update style/property enums on their owning types.
6. Migrate `InputEventKind::Text(String)` to session-scoped `TextInput`.
7. Add TextField editor core and visual buffer.
8. Add wgpu rendering for TextField parts.
9. Execute seq06.2 Takumi scene lowering.
10. Execute seq06.3 platform IME adapters.
11. Wire seq06 coordinate/capture metadata and smoke/golden policies.

## Tests To Specify

- style syntax parse/recovery;
- style layer ordering;
- `Text` source variant lowering;
- View DSL lowering to `ViewProgram`;
- system color light/dark resolution;
- composition preedit updates do not mutate Binding before commit;
- stale text-input session commit rejection;
- focus-preserving toolbar click;
- modal forced blur composition policy;
- caret/candidate rect transform metadata;
- secure-field Agent/replay redaction;
- `ViewScene` primitive ordering and stable context ranges;
- wgpu smoke rendering for selection/caret/composition.

## Constraints

- No CPU-raster fallback path.
- No hidden DOM/textarea fallback path.
- No keydown-character insertion path.
- Keep platform IME APIs in adapters.
- Keep renderer free of OS/IME APIs.
- Keep product resource codec work in seq02.4.1.
- Do not patch seq02.4 AudioGraph acceptance criteria.

## Non-Goals

- Product View compact resource codecs; handled by seq02.4.1.
- Platform-specific IME API implementation; handled by seq06.3.
- Full Takumi-to-wgpu lowering; handled by seq06.2.
