# Seq-01.6.1 Product AWBC RuntimeStepResult Parity Closure

## Sequence position

This request follows seq-01.6 producer wiring. Seq-01.6 makes normal builders
emit canonical AWBC-only products and introduces a typed pre-execution block for
compact families whose `RuntimeStepResult` contract is not yet proven.

Seq-01.6.1 removes those blockers one family at a time without restoring a
structured product fallback.

## Invariants

- Canonical AWBC remains the sole Game-product executable payload.
- `arcweft-bundle` remains data/codec only and Sans I/O.
- Product players do not depend on compiler/lowering crates.
- Runtime behavior is compared at the shared `RuntimeStepResult` boundary.
- No family is unblocked merely because the compact VM can execute its opcode;
  host-visible state, ordering, suspension, diagnostics and statistics must
  match.
- Extend owned Arcweft enums/types directly when a missing behavior belongs to
  them; do not add extension-trait or endpoint helper detours.

## Blockers to close

### 1. Input, entry arguments, and root bindings

Define how entry signatures receive root bindings and how missing/type-invalid
arguments are diagnosed. Differential tests must cover empty, positional,
named-equivalent runtime bindings and retry behavior after a rejected step.

### 2. Pure helpers and intrinsics

Route AWBC pure calls through the supplied `RuntimeCallBackend`; preserve helper
identity, argument/result conversion, deterministic failures, accelerator
selection and `RuntimeExecutorStats` accounting.

### 3. Dialogue and line tasks

Emit the same dialogue/line events and effects as structured execution. Do not
auto-resume. Model explicit host progression, line-task child scheduling,
cancellation, cleanup and output stop reason.

### 4. Choice

Present the full filtered option set, preserve public IDs/labels/effects, wait in
`FlowFiberStatus::Choice`, accept explicit choice input, reject invalid or stale
selection, and resume exactly once. Remove first-option auto-selection.

### 5. Await and await-many

Emit stable task requests, preserve task/need IDs, pending effects, cancellation,
progress, failure and binding semantics. Add deterministic waiting-many state,
limit/order rules and partial completion tests.

### 6. Host calls and effects

Replace `RejectingVmHost` at the product adapter boundary with typed request and
immediate-result contracts. Map every `AwbcEffectKind` explicitly to existing
runtime effects/requests or to a typed unsupported capability error. No dropped
variant is allowed.

### 7. Content, stream, and source

Map ensure-content requests; maintain monotonic stream sequences and source
state; preserve close/error/idempotence semantics, event ordering,
backpressure/privacy/replay policies and retry behavior.

### 8. Budget and step modes

Prove one-op, output, blocked, done, failed and budget-exhausted stop reasons.
Specify interaction between VM quantum and host `max_ops`, and prove no duplicate
output when a yielded fiber resumes.

### 9. Traps and maps

Resolve compact code locations through AWBC source/display maps. Match
structured diagnostic message/category, source label/range/anchor, partial
output retention, fiber failure and retry behavior for verifier-safe runtime
traps.

### 10. Statistics and observation state

Match executed ops, task/source inputs, emitted source/stream/line/audio counts,
diagnostics, fast-path/pure-helper stats and final observation/fiber state.

## Test architecture

Create table-driven differential fixtures that lower one source/runtime plan to
both structured bytecode and canonical AWBC, feed identical scripted
`RuntimeStepInput` sequences, and compare:

- normalized and raw `RuntimeStepResult` output;
- fiber status and stop reason after every step;
- emitted requests/effects/events and their order;
- environment/observation/source/stream state at safe points;
- diagnostics and source maps;
- executor statistics.

Use one fixture family per blocker. A blocker enum variant may be removed only
in the same change that adds passing differential coverage for that family.

## Required focused tests

- dialogue waits and resumes only after explicit advance;
- choice presents all valid options and accepts explicit selection;
- await ready/progress/failure/cancel;
- await-many deterministic order, limit and partial completion;
- immediate and suspending host call;
- every effect kind, including unsupported-capability diagnostics;
- ensure-content, stream yield/close, source close/event ordering;
- one-op/output/budget-yield parity;
- source-mapped division/type/pattern/host traps;
- entry/root binding and pure backend/stat parity;
- product runtime-driver, runtime-host and native-player smoke after all blockers
  are removed.

## Completion gate

Seq-01.6.1 is complete only when:

1. `AwbcProgram::product_step_parity_blockers()` is empty for the supported
   product language surface generated by ordinary source fixtures;
2. every removed blocker has differential coverage;
3. decoded product AWFB execution never reads structured product bytecode;
4. source gates still reject direct `BytecodeVmExecutor` construction in Game
   product paths;
5. the full seq-01.6 command matrix, workspace clippy and structure audit pass.
