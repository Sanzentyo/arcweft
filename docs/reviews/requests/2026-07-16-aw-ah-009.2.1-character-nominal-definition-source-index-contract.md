## Landed substrate that must be consumed

- CharacterNominalType remains the sole semantic look/part/variant identity.
  Equality and hashing never contain aliases, display labels, source paths, or
  provenance.
- CharacterSymbolDescriptor already represents owner, look, part, and
  per-part variant symbols. The design must adopt it as the canonical
  descriptor unless it identifies a concrete structural defect in the current
  type. It must not introduce a parallel descriptor with the same identity.
- SourceBackedCharacterManifest retains a CharacterManifestSourceMap with
  revision-bound structural JSON key and value spans. Token paths cover owner,
  look, part, variant, selection, and other manifest fields.
- ProjectSymbolTable is the single authority for ordinary and external project
  symbols. RegisteredTypeCheckEnv resolves external declarations to typed
  owners. Canonical, compact, qualified, and alias spellings must not create a
  second character-specific symbol table.
- RegisteredSemanticWorld atomically pairs one ProjectSymbolTable with one
  RegisteredTypeCheckEnv. LSP publishes it through an
  AcceptedProfileEnvironment identified by an
  AcceptedEnvironmentGeneration. Failed rebuilds preserve the previous
  accepted generation and caches.
- SourceDocumentIdentity binds exact content provenance. SourceSnapshotId is a
  separate session-local incremental-lineage type owned by
  arcweft-source::identity and allocated/advanced by SyntaxDatabase. Neither
  may be derived from the other or reconstructed from a display name.
- source_label() and Display are presentation only and have no inverse parser.
- Current character source maps are registration inputs, but the accepted
  semantic environment retains decoded CharacterManifest values rather than a
  complete descriptor-to-token/document index. LspProfile also retains a
  runtime CharacterCatalog. That publication seam, rather than JSON token
  discovery itself, is the design problem.
- The current definition feature resolves effective presentation-style
  contributors. Character definition must compose with that behavior through
  an explicit precedence/result rule; it must not delete or silently shadow
  unrelated definition results.

## Design objective

Define one immutable, bounded, revision-checked index from
CharacterSymbolDescriptor to exact declaration provenance, and one typed
position query that resolves an authored character token through the accepted
semantic world to that descriptor and source location.

The index must preserve enough SourceDocument ownership to validate spans and
map them to LSP URIs without I/O in core, character, HIR, or sema data types.
It must be published atomically with the semantic world or by a precisely
specified generation-bound adapter state. A successful query must never depend
on repository text search, substring reconstruction, source_label() parsing,
or “first manifest wins”.

## Required decisions

### 1. Canonical descriptor and declaration identity

Freeze the exact public and internal Rust shapes used for owner, look, part,
and per-part variant definition queries. State how the existing
CharacterSymbolDescriptor is reused, what constitutes equality and ordering,
and whether any additional declaration handle is needed for source-index
storage. Any additional handle must have a distinct responsibility and may not
duplicate nominal identity.

### 2. Source-index owner and immutable state

Choose the crate and responsibility module that owns the descriptor-to-source
index. Define its constructor visibility, immutable fields, accessors, and
relationship to RegisteredSemanticWorld, RegisteredTypeCheckEnv,
ProjectRegistrationFacts, and AcceptedProfileEnvironment.

State whether the index is part of the registered world or a generation-bound
LSP adapter payload. In either case, define one atomic publication boundary and
prove that an accepted world cannot be paired with a source index from another
world, symbol revision, document revision, or generation.

### 3. Manifest token projection

Define the total projection from each CharacterSymbolDescriptor variant to the
corresponding CharacterManifestTokenPath and exact value span:

- owner to the root character value;
- look to its look ID;
- part to its part ID;
- variant to the ID under its owning part.

Specify how typed IDs map to manifest array positions without a string search,
how duplicate or inconsistent source facts fail, and how the index retains the
owning SourceDocument needed to validate and present each SourceSpan.

### 4. Cursor-to-symbol query

Define one typed query from document, exact content identity, cursor byte
offset, project world, accepted environment generation, and semantic context
to either one CharacterSymbolDescriptor or a structured result.

Cover canonical, compact, qualified, and arbitrary alias owner spellings;
expected CharacterNominalType for local look/part/variant spellings; same
member spelling across owners and across parts; incomplete/recovered source;
and a cursor on delimiters, qualification, or whitespace.

The query may consume existing typed parser/HIR/sema facts but may not parse a
formatted label, scan the repository, or invent a second alias resolver.

### 5. Definition result and URI adaptation

Specify the result type before LSP adaptation and the exact LSP mapping for
JSON files, .awchar directories, generated manifests, dependency-owned
manifests, non-file sources, and unavailable documents. Select whether a
character query returns one Location, LocationLink, an ordered list, or no
result in each case.

Core and semantic layers must remain Sans I/O. Path/URI conversion and
readability checks belong to project-loader/LSP adapters.

### 6. Open-document overlays and stale input

Select the authority when a manifest or Arcweft source is open with unsaved
content while the profile was loaded from disk. Define version checks,
SourceDocumentIdentity checks, accepted-generation checks, stale results, and
rebuild scheduling. A query may not combine an open source token with a disk
manifest index from another revision.

### 7. Incremental identity dependency

Choose whether definition resolution needs stable typed AST/SyntaxNodeId
attachment or can operate against exact SourceDocumentIdentity plus current
typed ranges.

If stable typed-node identity is required, make implementation explicitly
dependent on the accepted proof 01.1.1 typed-AST attachment contract and its
landed implementation. If it is not required, state the range/content-identity
algorithm that avoids that dependency. Do not create a local syntax-node ID,
raw integer ID, or parallel incremental database.

### 8. Cache and invalidation contract

Define all cache keys and invalidation events. At minimum address
AcceptedEnvironmentGeneration, project symbol world/revision, exact source
document revisions, manifest source changes with an unchanged semantic
fingerprint, profile replacement, failed rebuild, document close, workspace
removal, and shutdown.

CharacterInventoryDigest alone is insufficient for definition provenance.

### 9. Ambiguity and structured errors

Define stable typed outcomes for unknown owner/member, ambiguous alias,
ambiguous same-spelling member, wrong nominal family, wrong owning part, stale
world/revision/generation, missing token provenance, missing document,
generated/read-only source, non-file URI, and resource exhaustion.

State which outcomes produce no definition, an LSP-visible diagnostic, a
recoverable empty result, or a request error. Do not use formatted strings as
error identity.

### 10. Determinism and hard limits

Select exact inclusive production limits for indexed manifests, descriptors,
documents, aliases consulted, candidates, diagnostics, source bytes, and work.
Define arithmetic-overflow behavior, deterministic candidate/error ordering,
exact-limit success, and one-over atomic failure. A failed index build must not
advance the accepted environment or publish a partial index.

### 11. Existing definition composition

Define precedence and combination with the current presentation-cascade
definition feature and future ordinary symbol definitions. A character token
must not accidentally return style contributors, and a style token must not be
captured as a character member merely because the spelling matches.

### 12. Rename-ready boundary without rename behavior

Freeze exactly which descriptor, declaration source, and occurrence facts
AW-AH-009.2.2 may consume. This task may reserve a typed occurrence/query
interface where necessary, but it must not select rename categories, construct
WorkspaceEdit values, or implement mutation policy.

## Ownership and dependency constraints

- arcweft-character owns character IDs, manifests, structural manifest token
  paths, and CharacterSymbolDescriptor; it performs no filesystem or LSP I/O.
- arcweft-lang-hir owns project symbols and HIR source references, not LSP
  locations.
- arcweft-lang-sema owns semantic resolution and registered-world facts, not
  path reads or WorkspaceEdit construction.
- project-loader owns filesystem-backed SourceDocument loading.
- arcweft-lsp owns document overlays, URI mapping, accepted profile
  generations, request results, and protocol errors.
- Do not add a global string map, compatibility alias, dual resolver,
  deprecated API, inverse source-label parser, or source-name reconstruction.
- Do not redesign AW-AH-009.1.1 registration, proof source identity,
  completion, hover, presentation cascade, or unrelated LSP symbols without
  concrete failing evidence.

## Implementation order to specify

The final contract must turn the following into compiling, reviewable cuts:

1. Freeze descriptor/source-index/query/error/limit APIs and measure current
   owner files.
2. Build the immutable descriptor-to-token/document index from validated
   source-backed registration facts.
3. Publish the index atomically with the accepted semantic world/generation.
4. Add typed cursor resolution through ProjectSymbolTable and registered
   nominal facts.
5. Adapt typed definition results to LSP URIs and compose with existing
   presentation definition.
6. Add open-document overlay, invalidation, stale, exact-limit, and shutdown
   behavior.
7. Remove any character-definition placeholder or bypass made obsolete by the
   accepted path; do not begin rename in this cut.
8. Run focused/workspace validation and the canonical structural audit at the
   reviewable cut point.

The plan must name exact crates/modules and deletion points. It may not rely on
compiler errors to choose a public result.

## Required direct tests

The contract must map each test to an API and expected typed result:

- owner definition through canonical, compact, qualified, and arbitrary alias
  spellings;
- look, part, and per-part variant definition with exact JSON value ranges;
- same local spelling across characters, families, and parts resolving only
  through typed context;
- escaped JSON strings, Unicode IDs, CRLF, quote-excluding ranges, and
  .awchar-directory manifest paths;
- presentation-style definition behavior remaining unchanged on non-character
  tokens;
- open unsaved Arcweft and manifest documents versus disk state under the
  selected overlay policy;
- stale SourceDocumentIdentity, symbol revision, accepted generation,
  SourceSnapshotId, profile, and multi-root facts;
- failed environment/index rebuild preserving the prior generation, world,
  index, and cache;
- generated, read-only, dependency-owned, non-file, missing, and unreadable
  definition sources;
- exact and one-over every candidate/document/descriptor/source-byte/work
  limit, including arithmetic overflow and no partial publication;
- deterministic ambiguity and error ordering across repeated runs;
- SourceDocumentIdentity and SourceSnapshotId remaining non-interchangeable;
  and
- public behavioral evidence that no query parses source_label(), scans
  checked-in source, or selects the first matching manifest.

Tests must call parser, source, project-symbol, registration, index, and LSP
APIs. Automated source gates are prohibited: no test or script may read
checked-in implementation or documentation and pass/fail by searching for
symbols, paths, or spellings.

## Non-goals

- Rename, prepareRename, WorkspaceEdit, filesystem mutation, and migration
  aliases.
- Definition for unrelated Arcweft symbol families.
- Redesign of CharacterNominalType, CharacterRegistrar,
  ProjectSymbolTable, source identity, proof identity, completion, or hover.
- Persisted semantic/source-index codec unless current repository evidence
  identifies a real persisted carrier. Do not invent one for an in-process
  index.
- CSS/Takumi or removed language-syntax restoration.
