# Request: seq06.9c Compositing Capture, Hit Metadata, and Goldens Package

> **Superseded (2026-07-13):** Arcweft Style is now native-only. The CSS authoring and Takumi product-path premises in this request were removed; see [Native-only typed Style path](../../implementation/native-only-style-path-2026-07-13.md). Do not use this request to reintroduce or reimplement CSS/Takumi Style behavior.

## Goal

Close the evidence layer for seq06.9a/seq06.9b compositing work by extending
capture metadata, hit/object bounds, and visual fixtures for CSS compositing
features. The output must make filter/backdrop/mask/clip/blend behavior
reviewable without relying on manual screenshots alone.

## Dependency

This request should be designed after seq06.9a is available and may be designed
in parallel with seq06.9b if it treats the renderer implementation as a
dependency. Implementation should land after the compositor can emit useful
rendered evidence.

## Scope

- Extend selected object/layer capture metadata to include:
  layout bounds, visual bounds, hit bounds, clip bounds, mask bounds, effect
  outsets, compositing group id, and paint node id.
- Ensure capture metadata distinguishes plain primitive bounds from visual
  bounds expanded by blur/drop-shadow/filter effects.
- Add fixture scenes covering `filter`, `backdrop-filter`, `mask`, `clip-path`,
  and `mix-blend-mode`.
- Add visual smoke or golden fixtures for pinned environments. If exact PNG
  goldens are platform-sensitive, document pinned promotion review steps and
  keep non-pinned CI disabled or ignored.
- Add evidence JSON that can be reviewed without image promotion.
- Add source gates to keep native/platform identities out of capture schemas.

## Non-Goals

- Do not implement renderer shader effects here unless seq06.9b intentionally
  leaves a small evidence-only hook.
- Do not enable GitHub CI golden enforcement by default. If CI integration is
  designed, keep the expensive/exact visual lane disabled or manual-only.
- Do not use CPU-rasterized Takumi output as the expected image.

## Implementation Order To Specify

1. Audit existing seq06.5/seq06.6/seq06.7/seq06.8 capture and golden fixtures.
2. Add metadata fields and schemas for compositing group/effect evidence.
3. Add fixture scenes with stable object ids.
4. Add smoke capture commands and JSON evidence expectations.
5. Add optional exact PNG promotion workflow for pinned native environments.
6. Document how to review drift packets and when to promote baselines.

## Tests To Include

- Schema tests for new metadata fields.
- Fixture generation tests that validate stable ids and effect metadata.
- Smoke tests for visual evidence JSON.
- Optional ignored exact PNG tests for pinned Windows/macOS/native GPU runs.
- Source gate against CPU fallback and platform identity leakage.

## Expected Output

Return a zip package containing:

- metadata/schema implementation overlay;
- fixture scenes and expected JSON evidence;
- optional ignored PNG baselines or drift packets;
- `docs/design/seq-06.9c-compositing-capture-goldens-design.md`;
- `docs/implementation/seq-06.9c-compositing-capture-goldens-2026-06-29.md`;
- validation and promotion instructions;
- overlay manifest and checksums.
