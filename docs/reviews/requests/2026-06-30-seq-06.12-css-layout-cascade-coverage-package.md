# Request: seq-06.12 CSS layout and cascade coverage package

> **Superseded (2026-07-13):** Arcweft now has a native-only typed Style path. The CSS authoring, Takumi adapter, and CSS-named sample/tooling paths described below were removed; the remaining text is retained only as historical implementation evidence.

## Sequence position

Seq06.12 can be designed in parallel with seq06.11, but production integration
must respect the seq06.11 retained View frame path. This request focuses on the
CSS layout/cascade subset Arcweft should support directly and deterministically
for native and web.

Treat seq06.9 compositing and seq06.10/06.10a text work as existing substrate.
Do not route UI through browser layout, DOM text, canvas 2D, or Takumi raster
output.

## Problem

Takumi is the intended CSS cascade/layout source, and Arcweft owns direct wgpu
rendering. The repository has property invalidation classes and direct/composite
rendering contracts, but it does not yet have a clear production coverage matrix
for CSS layout/cascade behavior exposed through Arcweft View samples and fixtures.

The result is ambiguous support for ordinary CSS features such as selector
specificity, inheritance, custom properties, media/container queries, flex/grid,
gap, padding/margin, position/inset, min/max sizes, aspect ratio, and overflow.

## Goal

Design and implement a first production CSS layout/cascade coverage cut for
Arcweft retained View.

The output should say exactly which CSS features are:

- supported now;
- represented in product data but not rendered yet;
- accepted with structured diagnostics;
- intentionally rejected.

For the implemented subset, native and web must render through the same direct
wgpu/Takumi-lowered scene path.

## Required decisions

- Define the supported selector subset:
  - element/class/id/part;
  - descendant and child combinators;
  - pseudo-state selectors only where seq06.11 provides interaction state;
  - explicit rejection for pseudo-elements and unsupported structural selectors
    unless implemented.
- Define cascade and specificity:
  - author origin ordering between Arcweft style layers and CSS layers;
  - specificity scoring;
  - source order;
  - inheritance fields;
  - `!important` policy.
- Define token/custom-property handling:
  - whether CSS custom properties lower into `ViewStyleToken`;
  - how Arcweft style tokens and CSS variables interact;
  - diagnostics for unresolved variables.
- Define layout subset:
  - block/inline/block-like retained View behavior;
  - flexbox first-cut requirements;
  - grid first-cut or explicit non-goal;
  - margin/padding/gap;
  - width/height/min/max/aspect-ratio;
  - position/inset/z-index;
  - overflow and clipping behavior.
- Define environment queries:
  - color scheme;
  - contrast;
  - reduced motion;
  - text scale;
  - viewport/media/container query support or explicit rejection.
- Define evidence format for layout/cascade:
  - computed style snapshot;
  - selector winner/provenance;
  - layout boxes;
  - invalidation class.

## Implementation requirements

- Produce a zip package with docs, overlay/patches, tests, and validation notes.
- Implement only a coherent subset. Unsupported CSS must be explicit and
  diagnostic-driven, not silently approximated.
- Add or update a sample/fixture separate from `css-style-parity` if needed.
- Keep CSS layout/cascade data deterministic and backend-independent.
- Do not create browser-only behavior. Web and native must consume the same
  lowered scene.

## Tests to specify and implement

- Specificity and source order choose the expected declaration.
- Arcweft style layer plus CSS layer conflict resolves deterministically.
- CSS variable/token resolution works or emits a structured diagnostic.
- Flex/gap/padding fixture renders stable native/web layout, if in scope.
- Unsupported grid/container/media features are diagnosed if out of scope.
- Layout invalidation class is correct for paint-only vs layout properties.
- Visual smoke artifacts cover at least two viewport sizes and one high-DPI
  scale factor.

## Expected output

Return a zip named like:

```text
arcweft-seq06.12-css-layout-cascade-coverage-YYYY-MM-DD.zip
```

The zip should contain:

- CSS support matrix;
- implementation design;
- overlay source edits;
- sample/fixture updates;
- focused tests;
- validation instructions;
- explicit future-work list.

## Non-goals

- Do not implement transitions, keyframes, animation timelines, or advanced
  shader/effect gaps here; seq06.13 owns those.
- Do not redesign seq06.10a styled paragraph layout.
