The prior archive

common tooling infrastructure remain later work.

## Fixed substrate that must not be redesigned

- Keep one native typed Style pipeline and one `arcweft-view` cascade/resolver.
- Keep `when environment(...) { ... }` as the sole wrapper grammar, with the
  four exact fields `color-scheme`, `contrast`, `reduced-motion`, and
  `text-scale`; implicit conjunction; unique fields on an effective path; and
  no CSS, Takumi, media query, general expression, callback, or `matchMedia`
  path.
- Keep enum and boolean comparison equality-only. Keep all six comparisons only
  for checked text scale, whose source range is 50% through 400% at 0.1%
  precision and whose owned value is checked `TextScaleMilli(500..=4000)`.
- Keep environment activation at zero selector specificity and retain the
  existing cascade priority tuple.
- Keep environment guards on sheet rules rather than selector predicates, with
  canonical field order, bounded typed evidence, source provenance, strict
  product validation, and no source reparse at runtime.
- Keep equality-aware session-owned environment revisions, field-local Style
  dependencies, locale outside Style identity, and deterministic native/web/
  headless values.
- Preserve d.4.1 axis types, revision, usage, logical mapping, and physical
  computed boundary as separate facts.
- Preserve the unreleased direct-replacement policy: no aliases, dual readers,
  deprecated variants, migration shims, compatibility wrappers, or source
  gates.
- Do not design d.4.3 container semantics, d.5.1.1 public trace transport, or
  d.5.3 common LSP/document infrastructure.

## Required reconciliation decisions

Every item below must have one exact answer, Rust API, owner, error behavior,
and direct test. `TBD`, alternatives left to implementation, and “as needed”
APIs are not acceptable.

1. **Comparison ownership.** Current `ViewContainerPredicate` uses
   `ViewStyleComparison`, while the rejected contract both removes that type
   and claims container representation is unchanged. Select the final owner and
   type for container comparison without designing container-query semantics.
   State whether the old generic type remains, is renamed to a container-only
   type, or is replaced another exact way; update selector/product/Serde/API
   sketches consistently.
2. **Transition scope and owner.** Current production code retains computed
   transition descriptors but has no Style property-transition execution state.
   Either exclude active-transition rebase/continue/snap from d.4.2 and remove
   it from completion claims, or define the complete new subsystem: state key,
   owning crate/type, supported properties, interpolation, clock and sampling
   boundary, generation token, cancellation/rebase/continue/snap algorithm,
   budgets, reduced-motion interaction, prepared-frame commit, and tests.
3. **Checked owned and wire decoding.** Replace the contradictory derived
   `Deserialize` for `ViewEnvironmentCondition` with one exact checked route.
   Define raw wire types, public trait implementations, strict canonical-order
   decode, in-memory sorting policy, contextual source-owner validation, and
   direct decode behavior for empty, duplicate, over-limit, noncanonical,
   unknown, `null`, nested, and out-of-range records. No public decode may
   bypass the owned invariant.
4. **Presentation public types.** Fully define `TextScaleMilliError`,
   environment values/overrides/field sets, bit assignments and checked-set
   behavior, constructors/accessors, Serde policy, update and overflow errors,
   equality semantics, override removal, and atomic no-mutation outcomes.
5. **Syntax and recovery types.** Fully define
   `StyleEnvironmentUnsupportedValueKind`, parser error-kind representation,
   HIR recovery enums, constructors/accessors, and their mapping to stable
   diagnostic codes. Specify how arbitrarily long percentage integers,
   fractional overflow, signs, exponents, missing units, and unsupported values
   are retained and classified without overflowing an AST `u16` or entering
   the general expression parser.
6. **Native live-update delivery.** Define the exact initial option and live
   snapshot path into the event-loop-owned session, including public or adapter
   handle, event/channel/proxy type, thread and ordering rules, update error
   propagation, redraw/prepared-frame invalidation, provider absence, shutdown,
   and same-value behavior. A private `NativeSceneState` method alone is not an
   externally usable delivery contract.
7. **Web start and retained handle.** Reconcile the current
   `start_arcweft_player(...) -> Result<(), JsValue>` surface with the proposed
   `ArcweftWebPlayerHandle`. Freeze exported start signatures, handle creation
   and retention, multiple-player identity, drop/shutdown behavior, `Rc`/
   `RefCell` ownership, reentrant borrow failure, update ordering, strict JS
   snapshot decoding, error shape, redraw invalidation, and unchanged result.
8. **Player/cache update API.** Define how the session change set reaches
   `PlayerFramePlannerState`/`PlayerViewStyleState`, how selection and projection
   usage are stored, how cache hits return usage, how parent inherited identity
   is derived without unsound over-invalidation, and where environment
   generation is stored on prepared work. Include the exact projection-only
   system-color path.
9. **Feature-tooling API.** Define concrete Sans-I/O input/result types for
   environment formatting, completion, hover, semantic tokens, code actions,
   intrinsic navigation results, and subtree-versus-sheet incremental
   invalidation. Use typed AST/HIR/sema/CST facts; do not use source spelling
   searches or redesign d.5.3 transport.
10. **Complete ownership and decomposition plan.** Re-enumerate current call
   sites rather than listing only primary owners. The prior intake found at
   least 15 `ViewStyleRule::new` files and 17 `BundleSessionOptions` files.
   Record exact current byte/LOC measurements and specify responsibility splits
   before additions push `runtime-driver/src/session.rs` or bundle View
   `model.rs`/`codec.rs` over the repository's 2,500-LOC error threshold. Audit
   the already warning-level native scene owner as well.
11. **Reproducible verification.** Correct any legal-form count mismatch and
   freeze the exact feature/target matrix. Host workspace tests do not compile
   `cfg(target_arch = "wasm32")` Web code, so the contract must include a
   wasm32 compile gate and a reproducible behavioral test path for the strict
   decoder and retained handle.
