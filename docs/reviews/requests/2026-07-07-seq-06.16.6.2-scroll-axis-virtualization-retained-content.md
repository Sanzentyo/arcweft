# Seq 06.16.6.2 Scroll virtualization and retained content handling

Date: 2026-07-07

## Implementation status

2026-07-09: the first implementation cut from the package has landed in
`docs/implementation/seq-06.16.6.2-scroll-axis-virtualization-retained-content-2026-07-09.md`.
Implemented items include scroll policies, dual-axis rejection, eager
`LazyRow`/`LazyColumn` lowering, precision and explicit-region scroll routing,
keyboard page/home/end scroll routing, retained content range propagation, and
prepared-frame focus auto-scroll for materialized targets.

This request remains open only for the still-deferred full virtualization
contract: non-materialized child range records, Agent observe/capture exposure,
deterministic save/load representation, visual scroll indicators, elastic
overscroll visuals, and gamepad analog scroll routing.

## Sequence position

This request follows seq-06.16.6 scoped presentation handles/final View syntax
and seq-06.16.6.1 save/load scoped presentation handles. The current
implementation already lowers authored `Scroll` nodes into typed scroll-region
resources, runtime presentation snapshots, native/web input routing, visible
control clipping, stable ids, viewport width/height, axis, overflow policy,
style defaults, and player-scene scroll snapshots.

## Why this split is needed

The final View syntax package describes focus auto-scroll, internal
viewport/content separation, and future virtualized containers such as
`LazyRow` / `LazyColumn`. The current implementation has the typed vertical and
horizontal control-scrolling substrate, but the remaining behavior needs a
separate contract so native, web, Agent observe/capture, save/load, and retained
renderer content do not grow incompatible partial models.

This request must not redesign the already implemented scroll-region resource,
input ownership, save/load snapshot, or style-default substrate unless current
implementation evidence shows a concrete defect.

## Required decisions

- Decide whether a future `.both` axis exists or is rejected with a structured
  diagnostic. `.vertical` and `.horizontal` are already implemented as a typed
  resource/runtime/render/input contract and should not be redesigned without a
  concrete defect.
- Define keyboard, gamepad, touchpad precision, and Agent scroll action mapping
  on top of the existing x/y offset substrate.
- Define scroll range computation for retained content:
  - controls already lowered into prepared text/button resources;
  - authored images;
  - authored text/general retained View nodes once they become concrete
    renderer objects.
- Define how `ScrollViewport` and `ScrollContent` appear in debug/Agent
  observation without adding duplicate user-facing objects.
- Define focus auto-scroll policy:
  - default policy;
  - nearest/start/end behavior;
  - interaction with hidden/unmounted/released view handles.
- Define the first virtualization contract:
  - whether `LazyRow` / `LazyColumn` are syntax-only typed nodes in this cut or
    fully range-virtualized;
  - stable semantic ids for materialized and non-materialized children;
  - Agent observe/capture behavior for virtualized-out children.

## Implementation order

1. Extend View parser/lowering for `indicators`, `overscroll`,
   `auto_scroll_focus`, and any accepted `LazyRow` / `LazyColumn` vocabulary.
2. Route keyboard, gamepad, precision touchpad, and Agent scroll actions through
   the existing typed x/y offset model.
3. Compute scroll ranges from all retained resources contained by a `Scroll`
   View element, not only text controls and action buttons.
4. Apply x/y offsets and clip rectangles to paint, hit-test, focus, semantic
   observation, and selected capture metadata.
5. Add virtualization only after the typed range/observation contract is
   deterministic; if full virtualization is deferred, emit typed diagnostics or
   lower to non-virtual containers explicitly.

## Tests to specify

- Syntax tests for `LazyRow` / `LazyColumn` and invalid unsupported scroll
  options.
- Bundle/resource tests proving the existing vertical/horizontal axis contract
  remains unchanged.
- Runtime save/load tests for retained content scroll ranges.
- Native and web input tests for keyboard/gamepad/touchpad scroll routing and
  clamping.
- Agent observe/capture tests for horizontally clipped controls and retained
  images.
- Focus navigation tests proving focused children scroll into view.
- If `LazyRow` / `LazyColumn` are accepted, tests for materialized vs
  virtualized-out observation/capture behavior.

## Constraints

- Keep the canonical authoring term `view`; do not reintroduce `component` in
  DSL syntax, Agent JSON, or CLI flags.
- Do not add DOM/platform widget fallback behavior.
- Do not update checked-in PNG visual baselines from this request.
- Preserve deterministic save/load and rollback semantics for scroll state.
