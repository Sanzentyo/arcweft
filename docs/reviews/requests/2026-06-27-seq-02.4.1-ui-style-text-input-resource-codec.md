# Request 02.4.1: UI, Style, Text, Theme, and Text-Input Resource Codecs

## Sequence Position

This request is a post-seq02.4 follow-up. It must run after the seq02.4
AudioGraph resource codec cut is implemented or explicitly closed. It must not
modify the seq02.4 AudioGraph acceptance criteria.

It depends on:

- seq02.1 common resource wire primitives;
- seq02.2 runtime type, entrypoint, and adapter requirement compact sections;
- seq02.3 presentation/entity/source-map stable references;
- seq02.4 family classification that left UI as future/dependent;
- the UI/style/TextField data model from the UI Style / Text Input package.

## Request

Design and implement compact product resource sections for Arcweft native UI,
style declarations, text sources, theme/environment values, and text-input
metadata.

## Required Decisions

1. Define compact schemas for `UiProgramResource`: component view instructions,
   child spans, handler ids, state schema hash references, exported parts, and
   semantic targets.
2. Define compact schemas for `UiStyleResource`: Arcweft style programs, CSS
   source identity, token table, part rules, environment predicates, source-map
   references, and external CSS descriptor references.
3. Define compact schemas for `UiTextResource`: literal/localized/rich/display
   frame references, source ranges, reveal/cursor policies, and secure redaction
   metadata.
4. Define compact schemas for `UiInputResource`: TextField/TextArea/SecureField
   options, input purpose, autocorrect/spellcheck/capitalization, multiline,
   secure policy, composition-on-blur, and adapter capability requirements.
5. Define compact schemas for `UiThemeResource`: `SystemColor` palette overrides,
   color-scheme defaults, contrast/reduce-motion/text-scale defaults, and dark
   mode visual-golden ids.
6. Define cross-section references to seq02.2 adapter requirements, seq02.3
   presentation/entity/source-map resources, and AWBC handler functions.
7. Define decoder budgets for UI program instructions, style rules, tokens,
   selector depth, part count, text sources, input options, and palette entries.
8. Define patch compatibility fingerprints for each family.
9. Define inspection/export JSON views while forbidding product JSON fallback.

## Compatibility Rules

- Style color/token-only changes: `ContentOnly`.
- UI layout/style program changes that do not change handler ABI or input
  adapter requirements: `ContentOnly` with frame-boundary refresh.
- TextField input purpose, secure policy, or multiline changes:
  `RestartRequired` until adapter requirement fingerprints are integrated.
- Component handler ABI, state schema hash, or AWBC function binding change:
  defer to seq03 generation classification.
- Agent observe/redaction semantics change: conservative `RestartRequired`.

## Implementation Order

1. Add schema-only types and deterministic encode/decode tests for UI/style/text
   resources using seq02.1 common wire primitives.
2. Add product inspection/export views.
3. Wire product AWFB encode/decode for one family at a time, starting with
   `UiStyleResource` because it has the least runtime ABI impact.
4. Add `UiTextResource` and `UiInputResource` with source gates against JSON
   fallback.
5. Add `UiProgramResource` after component DSL lowering is stable.
6. Add patch fingerprints for migrated families.
7. Add runtime/player smoke paths that consume compact UI resources.

## Tests To Specify

- deterministic bytes for each UI/style/text/input/theme section;
- unknown optional/required field behavior;
- budget failures for selector depth, instruction count, token count, and text
  source count;
- CSS external descriptor references preserve file/embed identity;
- dark/light palette fingerprint changes are content-only;
- secure-field policy changes are restart-required under conservative policy;
- product AWFB decode rejects JSON fallback for migrated families;
- source gates prevent ad hoc UI resource table formats.

## Constraints

- Keep `arcweft-bundle` Sans I/O.
- Do not parse CSS inside `arcweft-bundle`; encode already-lowered typed style
  resources.
- Do not open external CSS files inside data-format crates.
- Do not duplicate patch compatibility logic in runtime-driver or players.
- Do not redesign seq02.4 AudioGraph or seq02.5 patch v2.

## Non-Goals

- Implementing platform IME adapters.
- Implementing direct wgpu rendering.
- Reopening AudioGraph codec schema.
- Adding fallback DOM/textarea or CPU-raster surfaces.
