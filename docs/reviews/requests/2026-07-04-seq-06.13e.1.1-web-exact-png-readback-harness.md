# Request: seq-06.13e.1.1 Web exact PNG readback harness for inset box-shadow golden

> **Superseded (2026-07-13):** Arcweft Style is now native-only. The CSS authoring and Takumi product-path premises in this request were removed; see [Native-only typed Style path](../../implementation/native-only-style-path-2026-07-13.md). Do not use this request to reintroduce or reimplement CSS/Takumi Style behavior.

## Sequence Position

Seq06.13e.1.1 follows seq06.13e.1 pinned PNG golden promotion. The native
baseline for `seq06_13e1_inset_box_shadow` has been promoted from the
user-approved current pinned Windows environment. This request covers the
remaining Web half only.

Do not redesign the already implemented seq06.13b-06.13e renderer, typed
box-shadow planner, Takumi lowering, WGSL `PASS_BOX_SHADOW` path, or the native
exact PNG baseline unless Web evidence proves a concrete defect.

## Why This Split Exists

The repository currently has Playwright/WebGPU application smoke coverage, but it
does not have a seq06.13e.1 browser/WebGPU exact readback harness that renders
the 320x180 compositor fixture and writes:

- candidate PNG;
- observe JSON with route evidence;
- `imq` JSON;
- Web environment fingerprint;
- command logs;
- review decision.

The existing Web collector preflight can classify Web requirements, but its
`--run` path only invokes the generic `web` smoke and does not produce the exact
fixture packet. A DOM/CSS screenshot fallback must not be used.

## Required Decisions

- Choose the browser runner and launch flags for the pinned WebGPU environment.
- Define how the Web harness imports or mirrors the existing native compositor
  fixture without introducing a second renderer contract.
- Decide the browser-side readback path: WebGPU texture copy/readback,
  WebAssembly-exported renderer readback, or another deterministic Arcweft-owned
  path. Do not use DOM/CSS screenshots.
- Define the Web environment fingerprint fields: browser name/version, runtime,
  WebGPU adapter label/backend/driver when available, DPR, canvas size, feature
  flags, `imq` version, Arcweft commit, candidate/reference hashes.
- Decide whether the Web reference should be promoted separately from native or
  compared only to a Web-specific baseline.

## Implementation Order

1. Reuse the current seq06.13e.1 fixture contract and native promoted baseline as
   source context, without changing the native PNG.
2. Add a repo-owned Web capture script or test that renders the same 320x180
   fixture through the Arcweft WebGPU path and writes
   `target/seq06.13e.1-inset-box-shadow-golden/web/seq06_13e1_inset_box_shadow.candidate.png`.
3. Write Web observe JSON containing the typed compositor route and fixture
   scene evidence.
4. Extend `tools/collect-seq06-13e1-inset-shadow-pinned-golden-evidence.rs` so
   `--mode web --run` invokes the exact Web capture path and validates the
   packet, rather than only running generic `npm test`.
5. Promote the checked-in Web reference PNG only after the same-run packet is
   complete and reviewed.
6. Update docs, policy JSON, and exact packet tests with Web-specific results.

## Tests To Specify And Implement

- Web exact PNG packet completeness for
  `seq06_13e1_inset_shadow_web_exact_png_packet_is_complete`.
- Web collector run that writes candidate PNG, observe JSON, imq JSON,
  environment JSON, command logs, and review decision.
- Web failure classification for missing WebGPU, missing browser runtime,
  missing candidate PNG, dimension mismatch, and `imq` failure.
- Regression that Web evidence uses the Arcweft typed compositor path and not
  DOM/CSS screenshots, SVG filters, canvas 2D fallback, or CPU raster fallback.

## Constraints

- Do not modify the promoted native PNG baseline unless a concrete native defect
  is proven.
- Do not weaken `max_mse=0.002` / `max_mae=0.003` without an explicit policy
  update and evidence.
- Do not move the exact Web PNG validation into the default fast workspace test
  route.
- Do not introduce browser DOM/CSS rendering as the reference path for this
  renderer fixture.

## Expected Output

A reviewable package or patch that leaves the repository with:

- checked-in Web reference PNG for the seq06.13e.1 fixture, or an explicit
  no-promotion decision with blocker evidence;
- complete same-run Web packet under
  `target/seq06.13e.1-inset-box-shadow-golden/web/`;
- updated exact packet tests and collector;
- implementation note updates with commands, metrics, environment fingerprint,
  and review decision.
