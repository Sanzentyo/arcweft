# Request: seq-06.13e.1 inset box-shadow pinned PNG golden promotion

## Sequence Position

Seq06.13e.1 follows the applied seq06.13e CSS inset box-shadow rendering
package. Seq06.13e implemented typed inset shadow planning, WGSL/compositor
rendering, focused plan tests, Takumi adapter coverage, and an ignored GPU
smoke test.

This request must not redesign seq06.13b-06.13e renderer, lowering, or shader
substrate unless the pinned evidence shows a concrete rendering bug.

## Why This Split Exists

Seq06.13e intentionally did not promote exact native/web PNG goldens because
that decision requires the repository's pinned visual-golden environment. The
implementation evidence is sufficient for renderer support, but exact PNG
baseline promotion is an environment-gated review task with different evidence
requirements from ordinary code implementation.

## Goal

Produce a reviewable package that promotes exact native and Web PNG golden
coverage for seq06.13e inset box-shadow rendering, using only a pinned
visual-golden environment and complete same-run evidence.

## Required Decisions

- Define the pinned native environment fingerprint required for this fixture:
  OS, GPU/backend, adapter label, driver, device pixel ratio, font state, and
  `imq` version.
- Define the pinned Web environment fingerprint required for this fixture:
  browser/runtime, WebGPU adapter, device pixel ratio, canvas size, and any
  required feature flags.
- Decide whether the existing seq06.13e ignored GPU smoke fixture should become
  an exact PNG golden fixture, or whether separate exact native/web fixtures are
  needed.
- Decide the exact acceptance metric for each fixture:
  strict hash, PSNR/SSIM, bounded absolute drift, or existing repository visual
  golden policy.
- Decide where candidate PNGs, observation JSON, `imq` reports, environment
  fingerprints, and review decisions are stored.
- Decide failure classification for missing pinned environment, missing `imq`,
  unsupported adapter, or WebGPU unavailability.

## Implementation Order

1. Read the current seq06.13e implementation note and visual-golden policy docs.
2. Run the native pinned capture path and collect candidate PNG, observation
   JSON, `imq` metrics, command logs, and environment fingerprint.
3. Run the Web pinned capture path and collect the same evidence class.
4. Compare candidates against any existing fixture baseline or create new
   baselines only after recording the decision rationale.
5. Add or update exact golden tests so non-pinned environments skip or classify
   correctly, while pinned milestone jobs fail on drift.
6. Update implementation notes and fixture documentation with exact command
   lines, results, and review decision.

## Tests To Specify And Implement

- Native exact PNG golden for rounded inset shadow plus mixed outer+inset card.
- Web exact PNG golden for the same scene and render state.
- Environment-gated skip/classification tests for non-pinned local runs.
- `imq` metric report generation or validation for promoted PNGs.
- Regression that the exact fixture still uses the typed Arcweft compositor path
  and does not fall back to DOM, CSS screenshots, SVG, canvas, or CPU raster.

## Constraints

- Do not update checked-in PNG baselines from an unpinned environment.
- Do not weaken existing exact native/web visual policy to make this promotion
  easier.
- Do not redesign `ViewBoxShadow`, `ViewBoxShadowPassPlan`, Takumi lowering, or the
  seq06.13e WGSL path unless pinned evidence proves a defect.
- Do not move exact PNG validation into the default fast workspace test route.

## Expected Output

Return a zip package named like:

```text
arcweft-seq06.13e.1-inset-box-shadow-pinned-png-golden-promotion-YYYY-MM-DD.zip
```

The zip should contain:

- pinned native and Web environment fingerprints;
- candidate and promoted PNG evidence, or an explicit no-promotion decision;
- `imq` metric JSON and command logs;
- exact golden test edits and fixture docs;
- implementation note updates;
- validation results and any remaining environment blockers.
