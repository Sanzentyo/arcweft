## Gap 1: statement-form `if let`

Stable language documentation and current semantics support:

```arcw
if let .Some(route) = state.route_override when route_available(route) {
    goto route
} else {
    goto @flow.title
}
```

Attached syntax represents ordinary `if` and statement `if let` under
`IfStatement`, with pattern/scrutinee/guard roles for the latter. The accepted
contract also defines `SyntheticRole::IfLetScrutinee` for an if-let expression
or statement. However, exact `HirStmtKind` contains only ordinary `If`; it has
no statement variant capable of retaining the pattern, locals, guard, and
branch scopes. Compressing it into ordinary `If`, fabricating an `ExprId`, or
dropping pattern locals is invalid.

Required decisions:

1. Select the exact `HirStmtKind` representation for statement `if let`.
2. Define exact fields for pattern, scrutinee, guard, then/else scopes and
   bodies, locals, optional else, poison, and source origin.
3. Specify scope/local/capture allocation order, the
   `IfLetScrutinee` synthetic owner/anchor, name visibility, and rollback.
4. Reconcile nested `else if let`, ordinary `else if`, omitted else, malformed
   pattern/equals/guard/body, and exact recovery nodes.
5. Specify sema, verifier, runtime-plan, formatter, LSP, CLI, and Agent
   migration without a statement-to-expression shim.

## Gap 2: unsafe-audit source/edit anchor

The semantic audit payload is locally determined by current typed ownership and
the accepted “existing statement semantics remain” rule:

```text
typed @unsafe identity
optional/recovered reason ExprId
has-SAFETY-documentation fact
audited child scope and StmtIds
```

No redesign of those semantic fields is requested. The unresolved issue is the
existing exact `UnsafeAuditInsertion` anchor at the opening brace. Tooling and
verifier `GenerateUnsafeAudit` diagnostics need that edit location, while the
accepted HIR contract makes source tables the sole span authority, prohibits
payload range clones, and defines no delimiter HIR ID/source-slot kind.

Required decisions:

1. Select one authority for the exact insertion/edit anchor: a retained syntax
   identity, a typed auxiliary HIR source slot, an explicit source-table entry,
   or another fully specified revision-bound model.
2. Define its exact public query API, lifetime, module/revision validation,
   stale/foreign behavior, and relationship to `SourceSpan`/`SourceEdit`.
3. Define missing/unclosed brace recovery and whether an edit is available for
   recovered/non-executable audits; never fabricate a range.
4. Specify verifier/LSP/CLI edit projection from the accepted snapshot and
   deletion of detached `UnsafeAuditInsertion` ownership.
5. State explicitly which audit data is session-only and which, if any, may
   enter project/verifier artifacts. Raw offsets must not enter runtime,
   AWBC, bundle, cache, save, checkpoint, or replay formats.
