# Follow-up request: seq06.4k.2 scene-windowed owned-window/runtime migration and `windowed.rs` deletion

Date: 2026-06-29
Parent request: seq06.4k player text-input/windowed path convergence

## Blocker

`crates/arcweft-player-native/src/windowed.rs` is not the normal player path, but it still contains behavior not proven migrated into `scene_windowed.rs`/`WindowedRuntimeOwner`:

- `WinitOwnedWindowDriver` registration with `NativeDesktopBackend::builder().with_owned_window_driver(...)`;
- owned cursor/window commands (`set_title`, `set_bounds`, mode changes, cursor icon/visibility/grab/position);
- owned-window `request_close` through `WindowCloseSignal`;
- `BundleRunnerSession::pump_main_thread()`;
- `NativeAudioRuntime::drain_events` and `submit_commands`;
- native audio events pushed back into the runtime session.

The inspected `WindowedRuntimeOwner::from_bundle` path creates `NativePatchEndpoint::from_awfb_bytes`, and the inspected endpoint starts `BundleSession::from_awfb_bytes`. The package environment did not prove an equivalent adapter-installer hook for owned-window driver registration on this path, so deleting `windowed.rs` would risk behavior loss.

## Ownership decision

- `scene_windowed.rs` owns the winit event loop and close signal pumping.
- `WindowedRuntimeOwner` owns the mutable runtime session and exposes typed methods for:
  - main-thread task pumping;
  - audio event injection;
  - scene-safe patch mutation boundaries.
- `window_driver.rs` remains the only implementation of winit owned-window/cursor behavior.
- `NativePatchEndpoint` or `WindowedRuntimeOwner` must provide a construction path that registers the owned-window driver before the session starts.

## Required implementation order

1. Add a session-construction API for `WindowedRuntimeOwner` that accepts a `NativeDesktopBackend` or a narrow owned-window adapter installer without leaking winit handles outside native crate.
2. In `scene_windowed::NativeSceneState::new`, create `WindowCloseSignal` and `WinitOwnedWindowDriver` for the primary scene window.
3. Start `WindowedRuntimeOwner` with the owned-window driver installed.
4. Move `pump_main_thread` into the scene redraw/about-to-wait turn before stepping runtime.
5. Move `NativeAudioRuntime` into `NativeSceneState` and route:
   - device/capture events to `runtime.session_mut().push_audio_events(...)`;
   - step audio commands to `NativeAudioRuntime::submit_commands(...)`;
   - generated command events back to the session.
6. In `NativeSceneApp::about_to_wait` or another event-loop-owned hook, check `WindowCloseSignal::take()` and call `event_loop.exit()`.
7. Run desktop owned-window samples on the normal scene path:
   - `samples/desktop-owned-window-demo.arcw`
   - `samples/desktop-owned-window-close.arcw`
8. Delete:
   - `pub use windowed::run_bundle_windowed as run_bundle_adapter_windowed`;
   - `mod windowed`;
   - `crates/arcweft-player-native/src/windowed.rs`.
9. Update `tools/source-gates/seq06_4k_text_input_windowed_gates.rs` so the file itself must be absent, not merely accompanied by this follow-up.
