# Request: seq-08.3 Trait Method Body Runtime Dispatch

## Sequence Position

Seq08.3 follows seq08.1 trait substrate and seq08.2 standard
`Iterator` / `IntoIterator`. It must not redesign the trait catalog, associated
type model, coherence rules, or standard iterator names unless current
implementation evidence proves a concrete flaw.

## Problem

Seq08.2 can type-check `for source in expr` through `IntoIterator` and can lower
built-in iterator families to runtime/AWBC iterator state. User-authored
`IntoIterator` witnesses are still not executable because trait method bodies
are not lowered into callable runtime/AWBC targets with witness dispatch.

This must not be solved with concrete `Range` / `Seq` fallback, `IntoSeq`, or
stringly helper dispatch. The missing piece is executable trait method bodies
and witness-aware runtime calls.

## Required Design

Specify and implement the final runtime dispatch model for trait methods:

- stable callable identity for trait methods and impl methods;
- how `Self`, generic parameters, and associated types are represented in the
  lowered callable signature;
- how a sema `TraitWitnessId` maps to runtime-plan and AWBC callable targets;
- how inherent method calls and trait method calls share or differ in lowering;
- how receiver forms such as `self`, `&self`, and `&mut self` map to Arcweft
  value ownership and deterministic runtime state;
- how `Iterator::next(&mut self)` updates iterator state without cloning or
  materializing the whole sequence;
- diagnostics for missing method body, unsupported receiver, ambiguous witness,
  or non-deterministic iterator state.

## Required Implementation

- Lower impl method bodies into runtime-plan callable targets.
- Add typed witness-call representation to runtime-plan and AWBC lowering.
- Replace the seq08.2 witness-backed iterator rejection with executable
  dispatch when the witness has a supported method body.
- Add tests for a user-defined type implementing `IntoIterator` and a matching
  iterator type implementing `Iterator`.
- Add tests for unsupported witness execution cases with structured
  diagnostics.
- Keep built-in range/seq/vector/array/slice fast paths non-materialized.

## Constraints

- Do not add a parallel trait/protocol system.
- Do not add compatibility shims such as `IntoSeq`.
- Do not use stringly names to rediscover conformance at runtime.
- Do not make `arcweft-core` depend on syntax, HIR, sema, verifier, CLI, LSP,
  filesystem, network, or platform adapters.
- Keep data-format crates Sans I/O.
