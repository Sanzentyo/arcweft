## Split reason

The returned package is internally contradictory at a result-changing digest
boundary.

Its `DIGEST_AND_GENERATED_SOURCE.md` shared scalar grammar says that no source
span participates in a manual digest. The accepted nominal catalog v2 section
then says that the existing catalog hasher, canonical order, and retained
non-opaque row grammar remain, with only the opaque semantic row gaining a tag
and producer string.

Current production does not satisfy both readings. In
`crates/arcweft-lang-sema/src/env/nominal.rs`, catalog digest v1 explicitly
hashes:

- `AcceptedNominalRecord::source` for every exact row; and
- `OpenNominalRule::source` for every open rule.

It also delegates every field to Rust `Hash`, iterates exact rows by the
`BTreeMap<TypePath, _>` key and open rows by
`BTreeMap<OpenNominalRuleId, _>`, and does not expose a separately specified
canonical byte grammar for all retained variants. Therefore “retain existing
grammar” includes source evidence and Rust-derived tag/field behavior, while
the shared rule excludes that evidence. Removing source spans also changes
every retained non-opaque/open digest, not only opaque rows. Either selection
changes cache/publication identity and golden vectors.

The returned package also labels its accepted nominal declarations as the
parent package's final shapes while changing them:

- the preceding package fixes
  `AcceptedNominalRecord::try_new_opaque(..., source: Option<SourceSpan>)`,
  while the immediate child uses `source: SourceSpan`;
- the preceding package fixes
  `pub(crate) AcceptedNominalType::new(declaration: AcceptedNominalId, ...)`,
  while the immediate child makes it public and accepts
  `Arc<AcceptedNominalId>`; and
- current production owns the input visibility as
  `AcceptedNominalInputVisibility`, while the child-shaped inventory uses the
  unexplained name `AcceptedNominalVisibility` without a rename/deletion or
  consumer migration contract.

These are not mechanical implementation choices. They change deterministic
identity, constructor reachability, allocation/ownership shape, optional
source semantics, and public symbol closure. The correction is intentionally
limited to these conflicts; it must not reopen the producer declaration
model.
