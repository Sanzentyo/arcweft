# Seq-04.1 Request: AWBO Parse and HIR Codec Package

## Sequence Position

This is the first implementation-ready slice of seq04 Persistent Compiler Query
Cache. It follows the existing `.awbo` object contract in
`arcweft-project::persistent_object` and must not implement read-through or
write-through cache reuse yet.

## Request

Design and implement deterministic compiler-private `.awbo` payload codecs for
the safe first persistent compiler objects: parsed syntax facts and HIR-body
exact objects.

Return the final work as a zip package in the established overlay-package
format. The package must be applicable to current `main` and include Rust
implementation, tests, implementation notes, and validation instructions.

## Required Scope

- Define deterministic `.awbo` payload structs for parse facts and HIR-body
  exact facts.
- Include schema version, compiler identity namespace, source digest, source
  range/span representation, diagnostics summary, and stable stage inputs.
- Encode enough parse/HIR evidence for later cache validation, but do not claim
  semantic or typecheck reuse.
- Keep `arcweft-project` Sans I/O. No filesystem reads/writes in this slice.
- Add deterministic encode/decode tests and malformed payload rejection tests.

## Non-Goals

- No read-through cache lookup.
- No write-through cache persistence.
- No `arcw build` integration.
- No typecheck, runtime-plan, bytecode, or link-plan reuse.
- No serialization of `HirModule`, `CompiledProjectModule`, or other unstable
  Rust internals as a persistent compatibility promise.

## Expected Zip Contents

- `overlay/` Rust implementation.
- Focused tests for deterministic bytes, round-trip, schema rejection, compiler
  identity fields, and malformed payloads.
- `docs/implementation/seq-04-1-awbo-parse-hir-codec-2026-06-28.md`
- `VALIDATION.md` with cargo fmt/check/test/clippy/structure-audit results or
  honest blockers.
- `README.md` with assumptions, API changes, apply order, and non-goals.
