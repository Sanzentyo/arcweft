## Sequence and objective

This request follows the implemented AW-AH-009.2.1 source index and explicit
file-backed LSP source registry. It may be designed in parallel with
AW-AH-009.2.1.1, but implementation must consume its final overlay transaction
if that contract changes source admission. It precedes AW-AH-009.2.2 rename.

Freeze the missing production seam for generated, dependency, read-only, and
non-file character declaration sources, including bounded generation-owned
missing/unreadable/unmapped diagnostics. Do not redesign the existing
`CharacterDefinitionIndex`, descriptor provenance, core query outcomes,
all-or-empty `LocationLink` adaptation, or accepted-generation publication.

## Required decisions

Provide one exact Rust shape, owner, visibility, codec/lifecycle rule, and direct
test for each item:

1. The adapter/project-loader API that seeds an exact `SourceDocument`, optional
   explicit URI, optional exact file path, ownership, and access category. A
   generated or non-file source is navigable only through an explicit URI.
2. Deterministic duplicate/conflict rules for logical IDs, complete identities,
   URIs, paths, ownership, and access. Display names are never navigation
   authority.
3. The generation-owned bounded diagnostic store and stable typed kinds for
   `missing_source`, `unreadable_source`, and `unmapped_source`, including source
   identity, profile key, ordering, deduplication, omission count, invalidation,
   and publication failure boundaries.
4. Exact target validation for open URI sources, closed file sources,
   immutable generated sources, dependency/read-only sources, and non-file
   sources. Define changed, missing, unreadable, invalid-URI, and adapter
   identity-mismatch behavior without partial co-definition results.
5. Refresh scheduling and cache interaction when target availability changes
   after a typed core result was cached. Protocol `LocationLink` values and
   availability failures themselves must not be cached.
6. Inclusive source/diagnostic/work limits, arithmetic overflow, and atomic
   preservation of the previous accepted generation.

## Required tests

Specify JSON file, `.awchar` directory, generated-with-URI,
generated-without-URI, dependency, read-only, non-file-with-URI,
non-file-without-URI, missing, unreadable, invalid URI, changed identity,

typed APIs and observable behavior, never source spelling or file-placement
gates.

## Constraints

manifest or semantic index. No source-name parsing, first-usable target
selection, compatibility adapter, unbounded diagnostic list, CSS/Takumi,
rename, signature help, or redesign of landed Style/View/proof boundaries.
