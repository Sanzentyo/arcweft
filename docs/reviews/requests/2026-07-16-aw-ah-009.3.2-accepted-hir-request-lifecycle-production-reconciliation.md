# Design request: AW-AH-009.3.2 accepted HIR and request-lifecycle production reconciliation

- Date: 2026-07-16
- Sequence: AW-AH-009.3.2, after AW-AH-009.3 and parallel-designable with AW-AH-009.3.1
- Kind: independently throwable final production-reconciliation contract
- Production changes: prohibited
- Output language: English

## Goal and dispatch contract

Freeze the exact accepted-generation carrier and request lifecycle that let the
AW-AH-009.3 LSP handler supply a document-bound `&SourceDocument` and
`&HirModule` to the sema query without reparsing source inside the feature,
mixing an open overlay with an older accepted world, or inventing module
identity.

Send this file by itself to exactly one assignee with current Arcweft `main`,
the root `AGENTS.md`, the Rust skill, and the original AW-AH-009.3 final-contract
ZIP. The assignee may design this request in parallel with AW-AH-009.3.1, but
must not choose that request's call-surface syntax model or redesign its exact
range carrier.

Return one decision-complete contract with exact Rust types, ownership,
visibility, construction, publication, lookup, stale checks, cancellation, and
invalidation behavior. Do not return alternatives, TBDs, a patch, or production
edits.

## Basis and unresolved production seam

The re-audit basis is Git commit
`328e362f811896ebf866002c458fe0b970976654`, Jujutsu change `wopypppm`. The
original package is:

```text
arcweft-aw-ah-009.3-character-nominal-signature-help-final-contract.zip
sha256 cdd1d7b764da238a6e4e8f3e774a3384017c8da5ffaea1969f2af279102a7cd5
```

The original contract requires `SignatureQuery::try_new` to receive one exact
`SourceDocument`, one exact document-bound `HirModule`, and the current
`RegisteredSemanticWorld`. Current production cannot supply that tuple without
an unselected policy:

1. `AcceptedProfileEnvironment` owns generation, profile key, registered world,
   accepted source documents, overlays, and caches, but no `HirProject`, module
   HIR map, or typed-tree snapshot.
2. `AcceptedSourceDocument` owns the exact source document, locator, ownership,
   access, and line index, but no canonical module path or HIR.
3. `DocumentSnapshot` owns current editor bytes/version and line index, but no
   accepted typed tree or HIR.
4. `ProjectSymbolTable::source_identity(module)` is a forward lookup. The LSP
   request starts with a URI/source identity and has no selected reverse
   URI/source-to-module/HIR authority.
5. Parsing and lowering in the signature feature would be a new per-request
   compiler path whose work, failure publication, project binding, and stale
   relation to the accepted generation are not specified by AW-AH-009.3.
6. The requested `SignatureRequestStamp` contains accepted/profile pointer
   identity and the sema query borrows an `AtomicBool`, but current signature
   dispatch exposes neither an exact accepted HIR lease nor a defined
   per-request cancellation/deadline owner.

Choosing on-demand parse/lower, retaining HIR in `RegisteredSemanticWorld`, or
publishing an accepted HIR registry in the LSP generation changes memory,
staleness, failure, and ownership semantics. Implementation must not select one
implicitly.

## Required decisions

The final contract must decide all of the following.

1. **Canonical carrier.** Define the exact immutable type that owns or leases
   document-bound HIR for one accepted generation, its crate/module owner, and
   whether it is part of `RegisteredSemanticWorld`, `AcceptedProfileEnvironment`,
   or another explicitly named accepted artifact.
2. **Keys and uniqueness.** Define exact typed keys for canonical module path,
   `SourceDocumentIdentity`, and URI lookup; reject duplicate/conflicting
   mappings atomically; specify modules without declarations and dependency or
   generated sources.
3. **Construction.** State where `parse_source` and
   `lower_document_to_hir` run, which already-built project HIR is reused, and
   how exact text equality and module binding are proven. The signature feature
   itself must not run a source substring parser, word parser, or independent
   project build.
4. **Overlay acceptance.** Decide whether a changed open document has no query
   until a matching accepted generation is published or whether an overlay HIR
   is transactionally included in that generation. Define identical-byte/new-
   version behavior and failed rebuild behavior.
5. **Request acquisition.** Give the exact handler input and method sequence
   from URI/profile mapping to one `Arc<LspProfileState>`, one accepted
   environment, one source document, one canonical module, and one HIR lease.
   Define all typed acquisition failures.
6. **Final stamp validation.** Freeze pointer/value comparisons before cache
   return and after computation, including profile replacement, generation,
   world, symbol revision, character digest/revision, document identity,
   document version, module/HIR identity, and URI remapping.
7. **Cancellation and deadline.** Name the owner of the borrowed `AtomicBool`,
   how `$/cancelRequest` reaches it, when request admission closes, how the
   deadline is selected, and how cleanup avoids leaked cancellation entries.
8. **Cache invalidation hooks.** Define direct APIs for document close,
   workspace removal, accepted replacement, failed replacement, and shutdown.
   A stale in-flight computation must never insert into either the old or new
   accepted cache.
9. **Limits and work.** Decide whether accepted HIR construction is outside the
   per-query work budget, and if so which existing build limits bound it. No
   unbounded parse/lower may be hidden behind a cache miss.
10. **Memory and structural ownership.** Specify whether HIR is shared rather
    than duplicated between registration and LSP, how accepted generations are
    released, and what exact measurements or limits prevent retained old
    generations from becoming unbounded.

## Required implementation order

Specify compiling cuts in this order:

1. introduce the final accepted HIR/source/module registry and validate it as
   part of candidate construction;
2. publish it atomically with the registered world and accepted generation;
3. add exact URI/source/module/HIR acquisition with typed stale failures;
4. add request cancellation/deadline ownership and final stamp validation;
5. add cache invalidation hooks for close, workspace removal, replacement, and
   shutdown;
6. connect the resulting lease to the AW-AH-009.3 sema query only after the
   AW-AH-009.3.1 exact call carrier has landed; and
7. run focused HIR/profile/session tests, workspace check/clippy/test, and the
   canonical structural audit.

## Mandatory direct tests

The contract must define observable tests for:

- one accepted URI resolving to the exact canonical module, document identity,
  and HIR source identity;
- a module with no declarations and a non-root module;
- duplicate source identity, duplicate URI, and conflicting module mappings
  rejecting candidate publication atomically;
- an unchanged accepted overlay, a changed overlay with successful rebuild,
  and a changed overlay with failed rebuild;
- identical bytes with a new LSP version;
- profile pointer, generation, world, symbol revision, character inventory,
  document, module, and HIR changes during an in-flight request;
- cancellation before work, during work, and immediately before publication;
- deadline expiry, document close, workspace removal, replacement, and
  shutdown with no stale cache insertion;
- old accepted `Arc` readers remaining memory-safe while their publication is
  rejected; and
- construction and dependency evidence through typed APIs and Cargo metadata,
  never a source spelling/path gate.

## Fixed constraints and non-goals

- Do not redesign `CharacterNominalType`, the AW-AH-009.3 result/cache semantics,
  or the AW-AH-009.3.1 authored call model.
- Do not add a second `HirProject`, source parser, or type-check environment as
  a successful LSP fallback.
- Do not forge `SourceSnapshotId`, derive it from
  `SourceDocumentIdentity`, or add a signature-specific syntax database.
- Do not add source gates, compatibility wrappers, deprecated accessors,
  stringly module keys, CSS/Takumi, or removed-syntax diagnostics.
- Proof-concurrency typed-node identity is not a prerequisite unless current
  evidence proves the selected accepted-HIR carrier cannot preserve exact
  document ranges.
