## Eight required decisions

Each decision needs one exact Rust shape, owner, visibility, error/state rule, deletion
point, and direct test. Alternatives or implementation-selected policy are incomplete.

### 1. One nominal classifier

Make `CharacterNominalFamily` and inherent `family()` the final API. Directly
replace existing `CharacterNominalKind` and `kind()`; retain no alias,
forwarder, duplicate enum, or extension trait. Inventory all callers.

### 2. Typed external-owner reverse map

Keep HIR `ExternalDeclarationId` domain-neutral and opaque. Define one
sema-owned registry inside `RegisteredTypeCheckEnv`, equivalent in role to an
`ExternalDeclarationId -> RegisteredExternalOwner::{Character(CharacterId),
Environment(EnvironmentBindingId)}` map. Freeze construction, lookup,
world/revision binding, descriptor participation, and atomic unknown,
duplicate, conflicting, wrong-kind, and stale failures. Lookup must never parse
an external key, label, or path.

### 3. Exhaustive mismatch traversal

Inventory every current `TypeKind`. Provide a total table saying whether each
variant descends, child order, exact `TypeMismatchPathSegment`, and behavior for

variants. One inherent `TypeKind` method returns the first deterministic
mismatch; precedence is family, owner, then variant part. Ordinary outer-type
failure must not be hidden.

### 4. Cache scope and base-environment invalidation

base facts. Publish it and invalidate/namespace caches atomically; failed rebuild keeps
old generation/cache. Define overflow, rebuild, and shutdown order. Compiler semantic
reuse needs a future complete environment descriptor; read-only lowered-HIR cache hits
and post-registration pending-store flush stay.

replacement.
