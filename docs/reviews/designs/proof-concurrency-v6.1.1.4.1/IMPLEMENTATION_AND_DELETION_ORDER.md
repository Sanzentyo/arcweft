# Implementation and deletion order

This is a single public authority switch implemented in private compiling cuts. A cut may compile internally, but no old/new public dual surface may exist.

1. **Freeze baseline and transaction tests.** Re-run package intake, record the chosen main SHA, and add typed rollback/source-query test scaffolding. Do not add source scans.
2. **Install private final leaf owners.** Add names, paths, separate type regions/registry paths, arbitrary numeric/decimal/Duration payloads, child records, and extended source-role inherent APIs in `arcweft-lang-hir`. Extend Arcweft-owned enums in their original impls; do not add extension traits or ad-hoc match helpers.
3. **Install the private 35-variant expression and 12-variant pattern arenas.** Reuse the accepted ID/snapshot/transaction architecture. Add typed constructors/accessors and same-module validation. Keep the public old authority disconnected.
4. **Lower attached typed syntax directly.** Publish parent + role + ordinal source rows in the same transaction. Add compact numeric, associated receiver TypeId, Thread flow body, and exhaustive Dialogue/RichText lowering. No raw source reader or syntax clone is permitted.
5. **Migrate semantic analysis.** Resolve paths with immutable module context; check arbitrary numbers and exact float/Duration rules; project associated type callees to the existing shared resolver; publish checked RichText values. Delete provisional semantic leaf matches as each family moves.
6. **Migrate verifier and runtime-plan.** Consume typed expression/pattern IDs, checked numeric values, Thread plan, Dialogue/RichText checked IDs, and poison state. A poisoned node produces no executable plan.
7. **Migrate compiler and runtime.** Consume runtime-plan records only. Delete any compiler raw literal/path parser, flattened HIR Style reader, old dialogue call carrier, and Thread source inference.
8. **Migrate LSP, formatter, Agent/debug.** Query revision-bound source components by typed role/ordinal. Formatter uses attached syntax/source data, not semantic payload display strings. Delete vector-position reconstruction and detached text parsing.
9. **Migrate persistent cache and project publication.** Encode canonical checked records and project-generation identities. Reject stale/foreign IDs. Delete compatibility codecs, provisional cache payloads, and dual readers.
10. **Perform the one public compiling switch.** Replace old public expression exports with the final arena; delete ordinary `DialogueCall`, `MemoBlock`, `Raw`, inline call fields, provisional leaves, `hir::lower_source_document`, detached syntax conversion, raw unsafe-audit ranges, old flattened Style reader, source-string literal/path readers, and every obsolete consumer match.
11. **Validate.** Focused HIR/syntax/sema/resolver/dialogue tests; workspace check and Clippy; normal workspace tests; Tier 2 when runtime/render/Agent paths are touched; compile-fail API tests; rollback/stale/foreign tests; structural audit. The one-off residual-source review is review evidence only and is not checked in as a source gate.

## Failure policy

A contradiction in an accepted predecessor stops only the affected public switch and requires a new design correction. It may not be resolved with an alias, wrapper, shim, default, fallback, second resolver, textual reconstruction, or temporary public V2 shape.
