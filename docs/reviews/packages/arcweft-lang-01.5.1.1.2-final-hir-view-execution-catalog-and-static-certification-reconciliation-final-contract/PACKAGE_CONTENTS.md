# Package contents

The archive is standalone and design-only. It currently contains the following
normative/evidence categories before integrity envelopes are added:

- final status, request provenance, instructions, and repository evidence;
- complete contract, owner/API/Rust schema, semantic catalog, dynamic execution,
  image/resource/animation, static proof, runtime parity, parameter/default/export,
  diagnostics, wire/save, and work-accounting specifications;
- producer/consumer/migration/deletion matrices and an eight-cut compile-clean plan;
- `473` normative tests in CSV plus grouped/Tier-2 indexes;
- requirements traceability, decision/non-goal ledgers, source inventory, exact gate
  commands, and machine-readable contract model.

No `.rs`, `.patch`, `.diff`, production checkout, Cargo manifest, build output,
cache, credential, or implementation overlay is present.
