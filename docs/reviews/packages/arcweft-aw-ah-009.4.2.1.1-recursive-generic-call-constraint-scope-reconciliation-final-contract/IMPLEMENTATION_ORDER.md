# Implementation order

These stages are one coherent production replacement, not separate permission
to commit temporary public APIs or partially migrate the existing WIP.

1. Re-read the current main/index/dirty state and this complete package.
   Preserve the inherited migration. Confirm all source inputs still exist,
   rebase evidence conceptually against changed source, and rerun the two
   reproductions. Do not reset, branch, create a worktree or stash user changes.

2. Add the final scoped reference/binder behavior to the owning semantic type
   algebra. Replace generic payloads, const lengths and effect references.
   Migrate schema construction directly to bound templates and scope-bearing
   projections. Delete raw candidate declarations used as inference variables.

3. Replace lower scope, relation, normalization and completion. Retain the one
   structural visitor and exact transaction/failure/accounting protocol.
   Reify future slots only after normalization. Exercise rigidity, occurs,
   transitive bindings, nested binders, const/effect and privacy tests.

4. Migrate ValuePreparation/ApplyGroup, lexical owner projection, the sole
   preparation gate, prepared/frozen inheritance and atomic call sealing.
   Preserve all already bound keys, including future slots solved early.
   Delete duplicate deferred binding state and ambiguous substitution getters.
   Run the full sema library suite; do not disable the recursive regression.

5. Replace compiler layer chains with one closed substitution and a bounded
   instance-session worklist. Move that cohesive responsibility to
   lower/project_instances.rs. Exercise self/mutual/finite-polymorphic graphs,
   exact inclusive limits, cancellation and unchanged prior generations.

6. Extend normalized/core type admission and version-1 codecs for function
   binders, scoped bound subnodes, const lengths and effect rows. Enforce exact
   scope edge joins and closed ABI roots. Migrate runtime/compiler visitors,
   diagnostics, type identity and structural projections together. No legacy
   type reader or placeholder runtime type remains.

7. Migrate continuation scheme and Unapplied position projections through
   native/AWBC/restore. Keep nonterminal groups as values and terminal targets
   as closed instances. Exercise the reusable later-generic prefix, mixed
   caller/future identities, closure captures, exact expected ABI and codecs.

8. Complete every matrix row and the affected parent validation. Review
   changed structural boundaries by responsibility/dependency/API/test
   cohesion. Run applicable format, workspace check, Clippy and canonical
   structure gates, then the required repository-wide tier for the full
   parent result. Fix all newly exposed consumers; do not define completion
   around the easiest compilable subset.

9. At the coherent fully validated cut, inspect explicit staged paths/hunks
   and the cached diff, commit and push on the existing main checkout under
   repository policy. Record the full accepted SHA and the actual validation
   result. If an independent concrete-callback or other parent requirement is
   still failing, report that parent as incomplete; this package's readiness
   cannot supply implementation credit for it.

No production change is included in this design artifact. The failed baseline
controls stay visible until their final replacement passes. The selected
design does not require a second design recipient or a model-specific agent.
