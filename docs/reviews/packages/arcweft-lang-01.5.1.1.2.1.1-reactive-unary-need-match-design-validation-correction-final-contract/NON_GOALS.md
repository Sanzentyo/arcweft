# Non-goals and forbidden additions

Not added/redesigned: Need timeout; Stream/Watch; View suspension; AwaitView;
broader mount syntax; Dialogue/Ruby; Choice; CSS; Takumi; Result/Option
propagation; resources; generic RuntimeValue; AWBC ABI; backend-specific semantics;
or production overlays.

Forbidden: View VM, ViewRuntimeValue, arbitrary FxRuntimeValue payload fallback,
source reconstruction/identity, copied endpoint/task catalogs, extension traits or
helper detours for Arcweft-owned behavior that belongs in the original impl,
compatibility aliases/re-exports, dual readers, V2 wrappers, and empty/debug-string
fallback.
