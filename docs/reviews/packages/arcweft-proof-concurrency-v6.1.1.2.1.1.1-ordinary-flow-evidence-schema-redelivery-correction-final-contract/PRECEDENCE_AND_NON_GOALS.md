# Precedence and non-goals

## Normative precedence

The following order resolves overlap. Later rows may refine only the named
boundary and do not reopen an earlier accepted owner.

1. Current repository `AGENTS.md` at the inspected commit.
2. This corrected redelivery request.
3. The complete primary ordinary-Flow request.
4. The repository-local v6.1.1.2.1 item/member decision.
5. Accepted Proof qualified identity, arena, liveness, transaction, source
   query, tail/generator, Call, Select, Predicate, Proof, Function, and public
   switch decisions.
6. Accepted AW-AH-009.4.2/.3 dialogue application and line-identity decisions.
7. Accepted Lang-01.1.1 nominal, callable, and effect identities.
8. Maintained language chapters.
9. Current production code only as migration and consumer evidence.

The rejected v6.1.1.2.1.1 archive has no normative schema authority. Its
identity is retained only as rejected-return evidence.

When a current provisional implementation differs from this package, this
package selects the final model. Implementation must remove the provisional
owner and fix compile fallout directly; it must not create an adapter.

## Explicit non-goals

This package does not design or implement:

- DirectFrame/StreamFactory runtime classification;
- generator execution, scheduler behavior, direct suspension execution,
  cancellation runtime, AWBC, save, replay, or hot-reload wire mechanics;
- CharacterDialogue runtime/View/Agent/save implementation beyond consuming the
  already accepted typed dialogue application;
- TTS production;
- Lang-01.3 Source-to-Stream, Lang-01.4 resource, or Lang-01.5.1 manifest
  implementation;
- runtime assertion execution policy;
- a new expression, statement, pattern, type, scope, local, proof, effect,
  callable, project, diagnostic, or source-range authority;
- a formatter redesign. The formatter migrates to the attached owner and
  preserves source/trivia through the syntax snapshot;
- any compatibility alias, wrapper, shim, deprecated API, V2 API, dual reader,
  migration map, source-string reparse, source gate, removed-syntax-specific
  final diagnostic, CSS path, or Takumi path.

## Historical text

Maintained chapters still containing `.say` examples or old explanatory
terminology do not authorize a legacy syntax/HIR carrier. The accepted
AW-AH-009.4.2/.3 owner and the repository's deletion-driven public switch take
precedence for implementation.
