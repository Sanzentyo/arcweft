# Supersession and retained substrate

## Narrow supersession

This contract supersedes only the assumption that every non-presentation final-HIR owner must enter runtime semantic fact publication. It also replaces string-only opaque-leaf schema diagnostics with typed paths where the accepted producer/semantic facts already exist.

## Retained without redesign

- ordinary function checked execution/suspension facts;
- checked callable catalog and resolution;
- unary Need/Await/Try model;
- accepted opaque checked-type owner and recursive composites;
- schema-derived project nominal layout hash;
- nominal record descriptor/value/external admission contracts;
- AWBC type rows, opcodes, function kinds, ABI and codec version 1;
- bundle save schema version 1;
- native/AWBC common runtime product authority.

## Explicitly not claimed

This contract does not implement authored suspending ordinary-function AWBC lowering. It defines when that missing capability is relevant and how it fails. A later contract may admit such functions by changing the exhaustive `CheckedOrdinaryFunctionEmission` result and adding a complete lowering/verifier/native/save design; it must not retroactively make unreachable declarations global roots.
