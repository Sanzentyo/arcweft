# Archive identity

Expected archive filename:

`arcweft-lang-01.5.1.3-generated-artifact-runtime-binding-fail-closed-final-contract.zip`

Expected single member root:

`arcweft-lang-01.5.1.3-generated-artifact-runtime-binding-fail-closed-final-contract/`

All sidecars are inside that root. No adjacent status, hash, manifest, or summary file is required.

The archive SHA-256 and byte length are intentionally not embedded here because embedding them would create a self-referential archive hash. They are computed after final ZIP creation and reported in the delivery response.
