# Compile-clean implementation and deletion order

Each phase is a buildable dependency cut. The final type used by later phases is introduced before its first consumer; no phase uses a placeholder, public temporary constructor, defaulted authority, boolean substitute, old reader, or translation layer.

1. **Retained lower vocabulary.** Land/verify `CharacterDialogueCustomFieldId` and `CharacterDialogueRuntimeRole` in `arcweft-interaction-model`; put tags, `ALL`, authored-role selection, and classification on the original inherent `impl`. Preserve accepted Serde spelling and limits.
2. **Generation authority first.** In core, land the final raw generation declaration/fact grammar, root newtypes with checked private wire DTOs, and the final non-Serde `AdmittedRuntimeGeneration`. Implement exact project/producer type lookup and catalog-digest provenance; no validator exists yet.
3. **Canonical value path.** Extend the existing `value::ownership::path::RuntimeValuePathSegment` with only `OpaquePayload`; update its inherent tag/order/Serde implementation, ownership walker, capture/iterator/nominal/restore/save diagnostics, and fixtures in one cut. Delete the retry's duplicate pattern-owned names; never add an alias.
4. **Checked diagnostics and context.** Add non-Serde `RuntimeCheckedTypePath`, complete `RuntimeValueShape`, structured errors, and sealed domain-bound `RuntimeCheckedValueContext`. `RuntimeNominalRecordAdmissionDomain::checked_values` is the only constructor path. Implement inherent `RuntimeCheckedType::validate_value`, unique Choice, shared work/depth, nominal descriptor lookup, and remove authority-bearing boolean calls in the same cut.
5. **Checked plan DTOs.** Add custom-Deserialize `RuntimeIndexPath`, `RuntimePlanTypeDeclaration`, `RuntimeTypedExpr`, `RuntimeTypedPattern`, exact plan site/slot/coordinate enums, and mandatory typed fields on current plan owners. All constructors are private or crate-visible and checked; no admitted plan publication yet.
6. **Runtime-plan lowering and plan admission.** Project accepted semantic facts into the final typed owners, validate complete expression/pattern node tables, derive the in-memory site map, resolve every site against the already admitted generation, and publish `AdmittedRuntimePlan`. Delete serialized `RuntimePlanTypedRootUse` and any self-authorizing root/type claim before this phase is declared green.
7. **Raw-plan execution cut.** Migrate all plan executors/converters/session inputs to consume `AdmittedRuntimePlan` or perform full admission internally. Raw `RuntimePlan` remains deserialize-only quarantine; remove `Deref`, `into_inner`, raw replacement, and verify-only execution paths.
8. **Checked AWBC schema.** Replace raw runtime types/constants/patterns/frame slots with the final mandatory typed owners; add private wire DTOs and exact type/reference/cycle validation. Add every closed slot enum from the normative CSVs. No generic `slot: u32` survives.
9. **AWBC site resolution and admission.** Resolve every actual AWBC owner field, then correlate the resulting declaration with the admitted generation. Add coordinate-only `AwbcTypedOrigin`, direct plan/AWBC transcript equality, and `AdmittedAwbcProduct` plus `AdmittedRuntimeProduct` pair publication. Delete serialized `AwbcTypedRootUse` and all root/type fields from origin evidence.
10. **AWBC execution cut.** Migrate VM, fiber, product-step, AOT/JIT/codegen, accelerator, session/hot-swap, native/Web/headless player, restore, and test helpers to admitted wrappers. Remove raw-program constructors/replacement/extraction before the phase is green.
11. **Layer-correct catalog bridge.** Add core generation catalog provenance and dialogue-owned `CharacterDialogueGenerationCatalogs<'generation>`. Compare Character/View/custom digests to the same admitted generation; validate only custom-field accepted-View relationships. Delete runtime-driver-owned wrapper, free target generation, `MissingCharacterView`, and caller digest authority.
12. **Atomic role issuance.** Extend current sema owners so one registrar transaction builds `AcceptedNominalWorld`, issues exactly six declarations plus derived Style registry, publishes callable/custom projections, and constructs `RegisteredTypeCheckEnv`. Delete relevant `Named` success and every reference to nonexistent `AcceptedNominalEnvironment`.
13. **Dialogue/restore/replay/View/save consumers.** Thread the catalog bridge and checked-value context through schema construction, normalize/clear/patch, codec ingress, restore/replay, ownership traversal, View activation, root/save/bundle ingress, and diagnostics. Preserve typed paths/errors; publish only after complete validation.
14. **Final deletion cut.** Delete unchecked nominal constructors/shape validators, public boolean authority success, descriptorless reconstruction, stale root-use tables, duplicate path types, generic slot ordinals, free generation scalars, old readers, aliases, defaults, and raw execution escapes. Replace stale fixtures with final owner constructors.
15. **Workspace gates.** Run focused tests, codec/golden/tamper/compile-fail suites, formatting, workspace check/test/Clippy, structure and dependency audits, and every applicable Tier 2 command. Record actual outputs in the implementation evidence note.

After each phase, format and compile the changed owner plus every direct downstream crate. A phase is not complete while any later authority is mocked or bypassed.
