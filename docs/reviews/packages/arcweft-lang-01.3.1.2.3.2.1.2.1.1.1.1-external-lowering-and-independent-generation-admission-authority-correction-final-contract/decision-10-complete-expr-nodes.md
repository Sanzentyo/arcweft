# Decision 10 — complete expression-node type facts

Every admitted `RuntimeTypedExpr` has exactly one fact at root path `[0]` and
exactly one fact for every present child generated by the exhaustive
`RuntimeExpr` traversal. Optional absence emits no child. There is no legal
non-root expression.

`RuntimePlanTypeDeclaration` has a closed kind:

- `Checked { checked_type, authority }`, which may issue typed sites and
  participate in project/producer root correlation; or
- `Operational(RuntimeOperationalType)`, which is matched by semantic identity
  and closed root-shape against an independently accepted project fact but
  never issues a checked-value root or AWBC origin.

The operational root-shape enum covers MatrixF32/F64, TensorF32/F64, Range,
Iterator, StructuralRecord, Map, Need, Stream, Source, ThreadHandle, Shared,
Reference, Function, and the composite root tags Sequence, Tuple, Choice,
Result, Option, Variant when a descendant prevents projection to the closed
checked-value algebra. The full normalized type remains identified by
`RuntimeSemanticTypeId`; the root-shape tag cannot alias two semantic types.

A tuple/sequence/variant whose complete normalized type projects to
`RuntimeCheckedType` uses `Checked`; one containing an unrepresentable
descendant uses the matching operational composite tag. `RuntimeValue` and
semantic-root mappings are exhaustive in `RUNTIME_PLAN_TYPE_KIND.csv`; all
expression edges are in `RUNTIME_EXPR_NODE_RESOLUTION.csv`.
