# Structure and decomposition plan

## 1. Baseline and measurement authority

The implementation starts from latest inspected `main` Git `76d39983ad8770a87d6e81745785b6b362a381b4`. The canonical checked-in structural audit is `docs/implementation/structure-audits/proof-concurrency-surface-identity-2026-07-15` and reports 2,853 files, 1,408 Rust files, 661,972 physical Rust lines, 90 Cargo manifests, zero structural errors, and 128 warnings.

The audit CSV is authoritative for bytes, physical lines, code lines, classification, generated status, and whether a file contains any `#[cfg(test)]` region. Its schema does not contain a numeric embedded-test-line field. Exact directly derivable embedded regions are recorded below; the implementation cut must extend its checked-in report with an `embedded_test_physical_lines` column calculated from the final source tree. This measurement addition changes no production API and does not leave an implementation choice open.

No in-scope current file is generated. Any generated file introduced by another concurrent cut must remain marked generated by the canonical audit and is excluded from hand-maintained facade/module size gates.

## 7. Post-split size gates

The implementation structural report must apply these gates:

1. public facade files are at most 250 physical lines;
2. ordinary responsibility modules are 300-800 physical lines;
3. the two justified parser/lowering visitor exceptions are at most 900 physical lines and must contain no embedded tests;
4. no changed hand-maintained file exceeds 1,200 physical lines;
5. no new file approaches the repository 2,500-line structural error threshold;
6. embedded tests move to sibling `tests.rs` or crate `tests/` files whenever a production file would exceed 800 lines;
7. `#[cfg(test)] pub(crate)` allocator seeds/corruption hooks stay beside the owning allocator but contain no behavior duplicated from production;
8. no facade re-exports a compatibility alias or deprecated old model.

Any exception must be written into the implementation note with exact bytes/LOC, ownership reason, and follow-up date before merge. No exception is pre-authorized by this contract beyond the two <=900-line core visitors above.
