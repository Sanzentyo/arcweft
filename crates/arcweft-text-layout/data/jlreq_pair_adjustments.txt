# Arcweft JLREQ punctuation pair adjustment source data.
# version: arcweft-jlreq-pair-adjustment-2026-06-12
#
# Format:
#   LeftClassOrAny; RightClass; KeepTogether; BreakPenalty; Notes
#
# LeftClassOrAny is one of the generated `JlreqPunctuationClass` names or `Any`.
# KeepTogether is true/false. BreakPenalty is a non-negative integer added by
# the vertical column planner when it breaks before RightClass after LeftClass.

Any; RepeatMark; true; 1000; iteration marks stay with the previous cluster
Dash; Dash; true; 1000; repeated dash/prolonged-sound marks stay together
Leader; Leader; true; 1000; repeated leader marks stay together
Closing; Opening; false; 25; avoid weak breaks between adjacent closing and opening punctuation
MiddleDot; Opening; false; 15; prefer not to separate middle dot from following opening punctuation
