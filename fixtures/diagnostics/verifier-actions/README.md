# Verifier action fixtures

These fixtures document the typed interchange shapes expected by Seq-07.2 consumers.

- `missing-proof.arcw` creates a verifier obligation with proof-stub/show-obligation actions.
- `agent-report.json` shows the report/action shape Agents should consume directly.
- `lsp-code-actions.json` shows both command-like and edit-bearing LSP action shapes.

CLI text is intentionally not part of these fixtures.
