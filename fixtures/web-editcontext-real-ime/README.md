# Web EditContext real IME fixtures

This directory contains the trace schema, manual-session template, unsupported-browser
fixture shape, and the packaging-sandbox blocked evidence for seq06.4h.

Only traces generated by `web/tests/editcontext-real-ime-harness.mjs` in a headed,
EditContext-capable desktop browser with a real Japanese IME should be treated as
acceptance evidence. Synthetic or blocked fixtures are deliberately labelled as such.
